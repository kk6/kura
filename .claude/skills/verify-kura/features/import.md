# 画像を取り込む

利用者は画像やフォルダを選んで（またはドロップして）ライブラリに取り込める。Kura は画像をライブラリの中へコピーし、元は残す。フォルダはカテゴリとして再現し、重複と非対応形式はスキップして結果を知らせる。

## Sub-features

- `import-folder`：フォルダを取り込むと、同名のカテゴリと子カテゴリができ、画像がそのフォルダへコピーされる
- `import-files`：画像を選んで取り込むと、未分類に入る
- `import-skip`：重複（ゴミ箱を含む）と非対応形式はスキップされ、スキップの一覧で理由が見られる
- `import-progress`：取り込み中は「取り込み中 N / M枚」と「取り込み中…」が出る
- `import-drop`：Finder からウインドウへのドロップ

## How to get to it (user POV)

- ツールバーの「フォルダを取り込む」
- ツールバーの「画像を取り込む」
- Finder からウインドウへドロップ
- ステータスバーの「注意：スキップ N件」を押す（スキップの一覧）

## Driving it with computer-use

Preconditions:

- `$V launch <id> empty` で作った空のライブラリ（library.md の「作る」）か、見本。見本に同じ src を入れると全部重複になる。
- `$V src <id> 30` で `runs/<id>/src/` がある。

- **フォルダを取り込む。** 「フォルダを取り込む」を押し、⌘⇧G で `runs/<id>/src` を選んで「開く」。ステータスバーに「取り込み中 …」が出て、終わると「完了：取り込み 30枚」「注意：スキップ 5件」。サイドバーに `src` とその子カテゴリ、「すべての画像 30」。
- **副作用。** `app.log` に `取り込みました：30枚、スキップ 5件`。`$V db <id> "select count(*) from images"` が 30。`$V db <id> "select count(*) from pending_ops"` が 0。`ls runs/<id>/lib/src/ポーズ/座り` に画像がある。`ls runs/<id>/src` の元の画像は残っている。
- **スキップの一覧。** ステータスバーの「注意：スキップ 5件」を押す。「取り込まなかったファイル」に、理由「同じ画像がライブラリ（ゴミ箱を含む）にあります」と「対応していない形式です」が出る。
- **もう一度取り込む。** 同じフォルダをもう一度取り込む。取り込み 0枚、スキップは全件になり、images の件数は 30 のまま。

## Gotchas

- 1枚目の取り込みは、サムネイルの生成で数秒かかる。ステータスバーの「完了」を待ってから DB を引く。
- `import-drop` は Finder とのウインドウをまたぐドラッグになる。Finder の grant と全画面操作の `left_click_drag` が要り、ウインドウの位置合わせが不安定。ボタンの入り口で通したことを、ドロップの検証済みとして報告しない。
- スキップの件数は `gen_dev_library.py` の中身で決まる（同じ枚数なら毎回同じ）。枚数を変えたら件数も変わる。
