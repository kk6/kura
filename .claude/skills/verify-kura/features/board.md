# アイデアボード

利用者はギャラリーの画像を専用のウィンドウのボードに並べ、動かす・拡縮する・重ねる・加工する。ボードは開いているライブラリの DB に自動で保存され、閉じる・切り替える・終了するときは保存を待つ。ボードのウィンドウは最前面に固定でき、ウィンドウ全体を透かせる。

## Sub-features

- `board-open`：ヘッダーの「アイデアボード」、「ウインドウ」→「アイデアボードを開く」（⌘B）で専用ウィンドウが1つだけ開く。設定の「アイデアボードを使う」を外すと入口が消え、開いていたボードは保存して閉じる（FR-701、FR-711）
- `board-manage`：「ボードを作成」「新しいボード」、上部の選択欄で切り替え、「…」→「名前を変更…」「削除…」（FR-701）
- `board-add`：詳細パネルの「ボードに追加」、右クリックの「ボードに追加…」、「ファイル」→「ボードに追加…」（⇧⌘B）から同じダイアログ（FR-701、FR-702）
- `board-canvas`：選択、範囲選択、⌘A、移動、四隅で拡縮、delete で外す、Space＋ドラッグ・中ボタンでパン、ホイール・ピンチでズーム、「全体を表示」「選択画像を表示」（FR-702、FR-703）
- `board-history`：右クリックの重なり順4項目、⌘Z・⇧⌘Z とメニューの「取り消す」「やり直す」（FR-702）
- `board-transform`：右クリックの「左右反転」「グレースケール」「右へ90度回転」「回転をリセット」「トリミング」「トリミングを解除」、回転のハンドル（Shift で15°刻み）（FR-706、FR-708）
- `board-window`：「最前面に固定」、「不透明度」のスライダー、「100%に戻す」、位置と大きさの保存（FR-705、FR-707）
- `board-lifecycle`：元画像のゴミ箱・見つからない・完全削除で枠になる、「ギャラリーで表示」（FR-104、FR-511）
- `board-save`：「保存中…」「保存済み」、保存の失敗と「再試行」、失敗中は切り替え・閉じる・終了が止まる（FR-704、NFR-13）

## How to get to it (user POV)

- ギャラリーのヘッダーの「アイデアボード」、メニューの「ウインドウ」→「アイデアボードを開く」（⌘B）
- ギャラリーの画像の右クリック、詳細パネル、「ファイル」→「ボードに追加…」（⇧⌘B）
- ボードのウィンドウの上の帯（aria-label「ボードの操作」の「…」、「ボードを選ぶ」、「新しいボード」、「全体を表示」「選択画像を表示」、「最前面に固定」、「不透明度」、「100%に戻す」、右端の保存の状態）
- ボードの画像の右クリック（重なり順、加工、「ギャラリーで表示」）
- 設定（⌘,）の「アイデアボードを使う」

## Driving it with computer-use

Preconditions:

- 見本のライブラリ（`$V launch <id>`）。ボードは0個。性能や最前面の確認はリリース用ビルド（`KURA_BUILD=release`）で行う。
- ボードのウィンドウの名前は「アイデアボード」、ギャラリーは「Kura」。両方が出ていることを `$V windows <id>` で確かめてから押す。

- **開く・作る。** ヘッダーの「アイデアボード」。「ボードを作成」→ 名前の欄に「新しいボード」→「作成」。`$V db <id> "select id, name, revision from boards"` に1行。もう一度 ⌘B を押しても `$V windows <id>` の「アイデアボード」は1つ。
- **追加。** ギャラリーで画像を3枚選び、⇧⌘B →「追加」。ボードが手前に出て3枚が選ばれる。`$V db <id> "select id, source_id, x, y, scale, stack_order from board_items where active = 1"` に3行。同じ1枚をもう一度追加すると、同じ `source_id` の行が増え、`lib/` のファイル数は変わらない。
- **配置と保存。** 1枚をドラッグして離す。右端が「保存中…」から「保存済み」になる。`boards.revision` が増え、その行の `x`、`y` だけが変わる。⌘Z で前の値、⇧⌘Z で後の値に戻る。
- **重なり順と加工。** 画像を右クリック →「最背面へ」で `stack_order` が最小になる。「左右反転」「グレースケール」「右へ90度回転」で `flipped`、`grayscale`、`rotation` が変わる。「トリミング」→ 範囲をドラッグで `crop_*` が入り、「トリミングを解除」で NULL に戻る。同じ画像の別の配置の行は変わらない。
- **視点。** ホイールで拡大し、ボードのウィンドウを閉じて開き直すと同じ表示に戻る。`boards.viewport_scale` が変わっている。
- **最前面と不透明度。** 「最前面に固定」を押し、`$V windows <id>` の「アイデアボード」の `layer` が 0 以外、ギャラリーは 0。スライダーを左端へ動かすと `alpha` が 0.3、「100%に戻す」で 1。`home/Library/Application Support/dev.kk6.kura[/debug]/settings.json` の `board_window` に `always_on_top` と `opacity`（百分率。100 なら不透明）が入る。`frame` はボードのウィンドウを閉じるか終了したときに入り、開いたばかりは `null`（2026-11-14、run `mvs-a` で確認）。ほかのアプリ（Finder など）を手前にしても固定中は「アイデアボード」が前に残る（screenshot）。
- **元画像との連動。** ボードを開いたまま、ギャラリーで追加済みの画像をゴミ箱へ移す。ボードに「ゴミ箱にあります」の枠。元に戻すと同じ位置に画像が戻る。完全に削除すると「削除された画像」とファイル名の枠になり、`board_sources.image_id` が NULL、`lib/.kura/thumbs/` からサムネイルが消える。
- **保存の失敗。** SKILL.md の「保存を失敗させる」で、ディスクイメージに置いたライブラリを開いてから外す。配置を動かすと「エラー：保存できませんでした（ライブラリのドライブを読めません。ドライブをつなぎ直してから、もう一度試してください）」と「再試行」。`app.log` に「ライブラリの DB を読み書きできません：…」。この間、ボードの切り替え、⌘W、⌘Q、⇧⌘O が止まり、エラーが出る（`app.log` に「保存を待ちます：…」と「保存を待てなかったので操作を中止しました：…」）。つなぐ前に「再試行」を押すと、かっこの中が「ライブラリが見つかりません（…）」に変わる。つなぎ直して「再試行」で「保存済み」、`app.log` に「ライブラリの DB を開き直しました」、DB に外れていた間の配置が入り、`pending_ops` が空。
- **OFF。** 設定の「アイデアボードを使う」を外すと、ボードのウィンドウが閉じ、ヘッダーの「アイデアボード」とメニューの2項目が消え、⌘B が効かない。`settings.json` の `board_enabled` が false。もう一度入れても自動では開かない。

## Gotchas

- ボードのウィンドウは別の NSWindow。`computer_batch` の screenshot は手前のものだけを写すことがあるので、押す前にどちらのウィンドウが手前かを確かめる。
- Kura が背面のまま `app_menu` で「編集」の項目を押しても、手前のウィンドウがないので何も起きない。先に Kura を手前にする。
- Space＋ドラッグ、Shift を押しながらの回転、実トラックパッドのピンチは computer-use で再現できなかった。未確認として報告し、利用者の確認（`docs/tasks/phase2-check.md`）に回す。
- Dock の「終了」は computer-use で Dock を操作できず、確かめられない。⌘Q（メニューの「Kura を終了」）で通したことを Dock の経路の検証済みとして報告しない。
- 保存のすぐ後は WAL に書かれている。`$V db` は WAL も写すが、書き込みの途中を写すと半端になるので、「保存済み」を見てから少し待って引く。
- 外付けドライブを外す確認は、必ず `.claude/tmp/verify-kura/` の下に作ったディスクイメージで行う。本物の外付けドライブを使わない。
