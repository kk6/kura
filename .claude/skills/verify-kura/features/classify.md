# タグとカテゴリを付ける

利用者は詳細パネルで、選んだ画像にタグを付け外しし、カテゴリを変える。タグはサイドバーに件数付きで並び、押すとその画像だけに絞り込める。カテゴリを変えると実ファイルがそのカテゴリのフォルダへ移る。

## Sub-features

- `tag-add`：「タグを追加」に名前を入れて Enter、または候補（「既存のタグ」）を押すと付く。新しい名前ならタグを作る（FR-406）
- `tag-recent`：この起動の間に付けたタグが、入力欄の下の「最近使ったタグ」に新しい順で5個まで出る。押すと付く。選んだ画像すべてに付いているタグは出ない。アプリを閉じると消える（FR-407）
- `tag-remove`：付いたタグの「<名前> を外す」（FR-406）
- `tag-filter`：サイドバーのタグの四角を押すたびに選ぶ・外すが切り替わり、一覧が絞り込まれる。2つ以上選ぶと「タグの組み合わせ」の AND・OR で結果が変わる。Escape か空いた所を押すとすべて外れる（FR-503、FR-504）。絞り込みは画面の中だけで、Rust を通らない
- `category-set`：詳細パネルの「カテゴリ」の入力欄に名前を入れて候補を Enter で選ぶと、カテゴリが変わり実ファイルが移る（FR-402、FR-405）
- 複数枚を選んでいると、タグとカテゴリは選んだ画像すべてに効く

## How to get to it (user POV)

- 一覧で画像を選ぶ → 詳細パネルの「カテゴリ」「タグ」
- サイドバーの「タグ」の見出しの下の四角と、AND・OR のスイッチ

## Driving it with computer-use

Preconditions:

- `$V launch <id>`（見本）。タグは0個。半角で入力できる状態にする（日本語入力がオンだと Enter が変換の確定に使われる）。

- **付ける。** 一覧の左上の画像を選び、「タグを追加」を押して `vtag` と入力し Return。詳細パネルに `vtag` と「×」、サイドバーに「vtag 1」。`$V db <id> "select t.name from image_tags it join tags t on t.id = it.tag_id where it.image_id = <id>"` が `vtag`。
- **最近使ったタグ。** 2枚目を選ぶ。入力欄の下に「+ vtag」が出る。押すとサイドバーが「vtag 2」。
- **絞り込む。** サイドバーの「vtag 2」を押す。見出しが「すべての画像 2枚」、ステータスバーが「2 / 30枚」。Escape で外れる。
- **カテゴリ。** 2枚目のまま「カテゴリ」の入力欄を押して `手` と入力し、候補の「src / 手」が出たら Return。ステータスバーに「完了：カテゴリを変更 1枚」、サイドバーの「手」が1増える。`ls runs/<id>/lib/src/手` にそのファイルがあり、元のフォルダにない。`pending_ops` が 0。
- 2026-11-14、run `mvs-a` で上の4つを確認（Return は全画面操作で押した）。

## Gotchas

- 背景操作の Return はタグの入力欄に届かない。文字は入るが確定しない。drivers/claude.md の全画面操作で押す。
- カテゴリの入力欄は、何も入力せずに Enter を押しても変わらない（未分類へ移さない）。
- 「最近使ったタグ」はアプリのメモリにだけある。起動し直すと空。
- タグの名前の変更・統合・削除（サイドバーの「タグを管理する」）、カテゴリの作成・名前の変更・削除・ドラッグでの移動は、まだ手順にしていない。確かめるときは、そのことを「通せなかった入り口」として報告する。
