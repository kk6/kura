# タグとカテゴリを付ける

利用者は詳細パネルで、選んだ画像にタグを付け外しし、カテゴリを変える。一覧と拡大表示の右クリックからもカテゴリを変えられる。タグはサイドバーに件数付きで並び、押すとその画像だけに絞り込める。カテゴリを変えると実ファイルがそのカテゴリのフォルダへ移る。

## Sub-features

- `tag-add`：「タグを追加」に名前を入れて Enter、または候補（「既存のタグ」）を押すと付く。新しい名前ならタグを作る（FR-406）
- `tag-recent`：この起動の間に付けたタグが、入力欄の下の「最近使ったタグ」に新しい順で出る。押すと付く。選んだ画像すべてに付いているタグは出ない。アプリを閉じると消える（FR-407）
- `tag-recent-setting`：設定の「タグ」の「最近使ったタグを出す」と「出す件数」（5、10、15）。初期値は出す・5件。アプリ全体の設定（`settings.json` の `recent_tags`、`recent_tags_count`）に保存し、起動し直しても残る（FR-419）
- `tag-remove`：付いたタグの「<名前> を外す」（FR-406）
- `tag-filter`：サイドバーのタグの四角を押すたびに選ぶ・外すが切り替わり、一覧が絞り込まれる。2つ以上選ぶと「タグの組み合わせ」の AND・OR で結果が変わる。Escape か空いた所を押すとすべて外れる（FR-503、FR-504）。絞り込みは画面の中だけで、Rust を通らない
- `category-set`：詳細パネルの「カテゴリ」の入力欄に名前を入れて候補を Enter で選ぶと、カテゴリが変わり実ファイルが移る（FR-402、FR-405）
- `category-context`：一覧と拡大表示の右クリックの「カテゴリを変える…」（既存のカテゴリ、または新しく作ったカテゴリへ移す）と「1つ上のカテゴリへ移す」。未分類か一番上の階層の画像を含むと「1つ上」は押せない（FR-416）
- 複数枚を選んでいると、タグとカテゴリは選んだ画像すべてに効く

## How to get to it (user POV)

- 一覧で画像を選ぶ → 詳細パネルの「カテゴリ」「タグ」
- 一覧か拡大表示で画像を右クリック →「カテゴリを変える…」「1つ上のカテゴリへ移す」
- ⌘, → 設定のサイドバーの「タグ」
- サイドバーの「タグ」の見出しの下の四角と、AND・OR のスイッチ

## Driving it with computer-use

Preconditions:

- `$V launch <id>`（見本）。タグは0個。半角で入力できる状態にする（日本語入力がオンだと Enter が変換の確定に使われる）。

- **付ける。** 一覧の左上の画像を選び、「タグを追加」を押して `vtag` と入力し Return。詳細パネルに `vtag` と「×」、サイドバーに「vtag 1」。`$V db <id> "select t.name from image_tags it join tags t on t.id = it.tag_id where it.image_id = <id>"` が `vtag`。
- **最近使ったタグ。** 2枚目を選ぶ。入力欄の下に「+ vtag」が出る。押すとサイドバーが「vtag 2」。
- **絞り込む。** サイドバーの「vtag 2」を押す。見出しが「すべての画像 2枚」、ステータスバーが「2 / 30枚」。Escape で外れる。
- **カテゴリ。** 2枚目のまま「カテゴリ」の入力欄を押して `手` と入力し、候補の「src / 手」が出たら Return。ステータスバーに「完了：カテゴリを変更 1枚」、サイドバーの「手」が1増える。`ls runs/<id>/lib/src/手` にそのファイルがあり、元のフォルダにない。`pending_ops` が 0。
- 2026-11-14、run `mvs-a` で上の4つを確認（Return は全画面操作で押した）。
- **右クリックで1つ上へ（FR-416）。** サイドバーの「座り」を押し、一覧で2枚を ⌘ を押しながら選ぶ。選んだ画像を右クリック →「1つ上のカテゴリへ移す」。ステータスバーに「完了：カテゴリを変更 2枚」。`ls runs/<id>/lib/src/ポーズ` にその2ファイルがあり、`座り/` にない。
- **右クリックで既存のカテゴリへ。** 「手」の画像を1枚選んで右クリック →「カテゴリを変える…」。見出しに「1枚」。「移す先」で「服飾」を選ぶと、ダイアログが閉じて移る。`ls runs/<id>/lib/src/服飾` にそのファイルがある。
- **右クリックで新しいカテゴリへ。** 「屋外」の画像を2枚選んで「カテゴリを変える…」。「新しいカテゴリ」に `参考`、「作る場所」に「背景」を選び「作って移す」。`$V db <id> "select id, name, parent_id from categories where name = '参考'"` に1行。`ls runs/<id>/lib/src/背景/参考` に2ファイル。
- **拡大表示から。** 画像をダブルクリックで拡大し、右クリック →「1つ上のカテゴリへ移す」。一覧と同じ結果になる。
- 各操作の後に `$V db <id> "select count(*) from pending_ops"` が 0。未分類の画像か一番上の階層（`src` の直下）の画像を含めて右クリックすると、「1つ上のカテゴリへ移す」が押せない。
- 2026-11-23、run `fr416` で上の4つを確認（証跡は `evidence/` の `up-*`、`existing-*`、`new-*`、`zoom-up-*` と `fr416-db.txt`、`fr416-files.txt`）。
- **最近使ったタグの設定（FR-419）。** 1枚目にタグを7個付ける（`t1`〜`t6`、`seven`）。2枚目を選ぶと「最近使ったタグ」が5個。⌘, →「タグ」で「出す件数」を10件にし、「ギャラリーに戻る」。2枚目の候補が7個になる。設定で「最近使ったタグを出す」をオフにすると、候補の欄が消える。`cat "runs/<id>/home/Library/Application Support/dev.kk6.kura/debug/settings.json"`（リリース用ビルドは `debug/` なし）で `recent_tags` が `false`、`recent_tags_count` が `10`。
- **起動し直して残る。** `$V relaunch <id>` で起動し直し、⌘, →「タグ」でオフ・10件のままであることを確かめる。最近使ったタグの中身（どのタグか）は起動し直すと空になる。
- **設定の「タグ」のタグ管理（FR-408）。** 同じ画面の「タグを探す」に `se` と入れると「seven」だけが出る。「名前を変える」（aria-label「「seven」の名前を変える」）で `seven` を `t7` にすると、`$V db <id> "select id, name from tags"` に残る。

## Gotchas

- 背景操作の Return はタグの入力欄に届かない。文字は入るが確定しない。drivers/claude.md の全画面操作で押す。
- カテゴリの入力欄は、何も入力せずに Enter を押しても変わらない（未分類へ移さない）。
- 「最近使ったタグ」の中身はアプリのメモリにだけある。起動し直すと空。残るのは、出すかどうかと件数の設定だけ。
- 「カテゴリを変える…」は、絞り込んだカテゴリから画像を移すと、その画像が一覧から外れる。ダイアログの後に選択が外れるのは正しい動き。
- タグの統合・削除、カテゴリの作成（サイドバーから）・名前の変更・削除・ドラッグでの移動は、まだ手順にしていない。確かめるときは、そのことを「通せなかった入り口」として報告する。
