# ゴミ箱

利用者は画像をアプリ内のゴミ箱へ移し、ゴミ箱から元のカテゴリへ戻したり、完全に削除したりできる。ゴミ箱へ移すとき確認は出ない。完全に削除と、ゴミ箱を空にするときは確認が出る。

## Sub-features

- `trash-move`：画像を選んでゴミ箱へ移すと、一覧から消え、サイドバーの「ゴミ箱」の件数が増える
- `trash-open`：サイドバーの「ゴミ箱」で、ゴミ箱の画像の一覧が出る
- `trash-restore`：「元に戻す」で元のカテゴリへ戻る
- `trash-purge`：「完全に削除」「ゴミ箱を空にする」は確認のあと、ファイルを消す

## How to get to it (user POV)

- 詳細パネルの「ゴミ箱へ移す」
- 一覧で選んで ⌘Delete
- サイドバーの「ゴミ箱」→ 右パネル（aria-label「ゴミ箱」）の「元に戻す」「完全に削除」「ゴミ箱を空にする」

## Driving it with computer-use

Preconditions:

- `$V launch <id>`（見本）。ゴミ箱は 0。対象の画像の id、名前、カテゴリのフォルダを `$V db` で控える。

- **ゴミ箱へ移す（ボタン）。** 一覧で1枚選び、詳細パネルの「ゴミ箱へ移す」を押す。一覧から消え、「すべての画像 29」「ゴミ箱 1」。`$V db <id> "select deleted_at from images where id=<id>"` が空でない。実ファイルは元のフォルダになく、`runs/<id>/lib/.kura/trash/<画像の id>.<拡張子>` にある（例：`3.jpg`）。`pending_ops` は 0。
- **ゴミ箱へ移す（キー）。** 別の1枚を選んで `key cmd+Delete`。「ゴミ箱 2」。
- **元に戻す。** サイドバーの「ゴミ箱」を押し、1枚目を選んで「元に戻す」。「ゴミ箱 1」。実ファイルが元のカテゴリのフォルダに戻り、`deleted_at` が空。
- **完全に削除。** ゴミ箱で残りの1枚を選び「完全に削除」→ 確認で削除を押す。「ゴミ箱 0」。images にその id の行がなく、`.kura/trash/` にファイルがない。
- **後片付けの確認。** `$V db <id> "select count(*) from pending_ops"` が 0。

## Gotchas

- ⌘Delete は、詳細パネルやダイアログに入力のフォーカスがあると効かない。一覧を押して選んでから押す。
- 完全に削除は元に戻せない。消してよいのは run のライブラリの画像だけ。
- ゴミ箱が空のとき、一覧には「画像がありません。「画像を取り込む」を押すか…」と取り込みの案内が出る（2026-11-06 時点）。空になった印として読む。
- ゴミ箱を開いている間は、並べ替え・絞り込み・拡大表示ができない。ほかの項目を押すと閉じる。
