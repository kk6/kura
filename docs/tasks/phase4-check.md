### 試し用のライブラリに元が同じ画像の組を入れる

見本の写真（`/Users/kk6/Projects/kura-library`、Unsplash の写真 231枚）から、`scripts/gen_same_origin.py` で変形した写しを作ります。見本の写真は読むだけで、変わりません。番号はしきい値の計測（要件定義書の4章）と同じになります。

```bash
uv run scripts/gen_same_origin.py /Users/kk6/Projects/kura-library .claude/tmp/kura-same   # 写真ごとに <番号>/original.jpg と9種類の写し
```

試し用のライブラリの中に `同じ元/` フォルダを作り、次のファイルを写してから、サイドバーの ↻（差分を確認）を押します（`L` は `同じ元/` のパス）。

```bash
O=.claude/tmp/kura-same L=<試し用のライブラリ>/同じ元
mkdir -p "$L"
for i in 0000 0001 0002; do cp $O/$i/original.jpg "$L/p$i-a.jpg"; cp $O/$i/scale50.jpg "$L/p$i-b.jpg"; cp $O/$i/recompress.jpg "$L/p$i-c.jpg"; done
cp $O/0134/original.jpg "$L/n.jpg"; cp $O/0134/crop75.jpg "$L/n 2.jpg"   # 名前が写しの形。類似度 0.882
cp $O/0052/original.jpg "$L/m.jpg"; cp $O/0052/crop75.jpg "$L/k.jpg"     # 名前が違う。類似度 0.895
```

- 期待する組：`p0000`、`p0001`、`p0002` の3組（各3枚）と、`n.jpg` / `n 2.jpg` の1組。`m.jpg` と `k.jpg` は組にならない（しきい値 0.98 に届かず、名前も写しの形ではない）。縮小 1/2 と JPEG の再圧縮は、写真の計測で中央値が 0.998 以上。写しが 0.98 に届かずに組から外れたら、別の番号の写真で試す
- `dev-library/` のダミー画像は内容の特徴量が近いので、まとめて1つの大きな組になることがあります。写真の組だけを見るときは、サイドバーで `同じ元` を選んでから探します（条件に合う画像を含む組だけが出ます）
- 類似画像検索を ON にし、特徴量の計算が終わってから試します

- [ ] `p0000-a.jpg` を選んで「似た画像を探す」を押し、結果で ⌘ を押しながら `p0000-a.jpg`、`p0000-b.jpg`、`p0000-c.jpg` を選ぶ。右クリックと詳細パネルの両方に「1枚にまとめる…」が出る。1枚だけ選んだときと、似た画像の結果でない一覧では出ない
- [ ] 「1枚にまとめる…」のダイアログで、残す画像に画素数の一番大きい `p0000-a.jpg` が選ばれている。タグは3枚のタグを合わせたもので、× で1つ外せる。カテゴリの選択欄で別のカテゴリを選べる
- [ ] 「まとめる…」を押すと、ゴミ箱へ移す枚数（2枚）の確認が出る。「ゴミ箱へ移す」を押すと、ステータスバーに「完了：1枚にまとめ、ゴミ箱へ移した 2枚」と出て、2枚が結果から消える。Finder で、残した画像が選んだカテゴリのフォルダにあり、2枚が元の場所にない
- [ ] 残した `p0000-a.jpg` の詳細パネルに、`p0000-c.jpg` に付けていた元URLが出る。タグは、ダイアログで外したもの以外が付いている
- [ ] 開いていたボードで、`p0000-b.jpg` があった場所に `p0000-a.jpg` が出ている。もう1つのボードを開くと、同じく置き換わっている。位置、表示の幅、回転、反転、グレースケールは元のまま。縦横比が違えば高さが変わり、トリミングは外れている
- [ ] サイドバーの「ゴミ箱」で2枚を選び「元に戻す」を押すと、元のカテゴリに戻り、それぞれ自分のタグと元URLを持っている。残した画像のタグと元URL、ボードの配置は変わらない
- [ ] 類似画像検索を OFF にすると、メニューバーの「ファイル」に「似た画像を探す」と「元が同じ画像の組を探す…」が出ない。⇧⌘F を押しても何も起きない
- [ ] ON に戻して「ファイル」→「元が同じ画像の組を探す…」を選ぶ。帯に「元が同じ画像」と組の数が出て、組ごとに見出しの行（枚数、「1枚にまとめる…」「一覧から外す」）で区切った一覧になる。`p0001`、`p0002` の組が出る（`p0000` はまとめた後なので出ない）
- [ ] `n.jpg` と `n 2.jpg`（名前が写しの形、類似度 0.882）は組になり、`m.jpg` と `k.jpg`（名前が違う、類似度 0.895）は組にならない
- [ ] 組の見出しの「1枚にまとめる…」を押すと、その組の全部の画像でダイアログが開き、まとめると組が一覧から消える。別の組の「一覧から外す」を押すと組が消え、Finder でもその画像は動いていない。帯の「閉じる」で元の一覧に戻る
- [ ] 設定の「類似画像検索」の「元が同じ画像の組を探す」の「探す」でも、同じ組の一覧が出る
- [ ] 2万枚のライブラリ（準備の節）で「元が同じ画像の組を探す…」を選ぶ。ステータスバーに「元が同じ画像の組を探し中」と進み具合が出て、60秒以内に組の一覧が出る。もう一度選び、出ている間に「中止」を押すと止まり、結果は出ない（速く終わって押せなければ、そのことを記録する）
- [ ] 試し用のライブラリで、Finder で `同じ元/n.jpg` を別のカテゴリのフォルダへ複製し（名前は `n-dup.jpg`）、サイドバーの ↻ を押す。ステータスバーの「注意：スキップ」を押すと、`n-dup.jpg` の行に「整理…」がある。「このファイルの場所に残す」を選んで「整理する」を押すと、登録済みの `n.jpg` がそのカテゴリへ移り、`n-dup.jpg` が `.kura/trash/.duplicates/` へ移る。アプリのゴミ箱には出ない。もう一度同じ手順で「登録済みの画像の場所に残す」を選ぶと、登録済みの画像は動かない（FR-109）
- [ ] アプリのゴミ箱に1枚以上入れてから「ゴミ箱を空にする」を押すと、`.kura/trash/.duplicates/` の中も消える
- [ ] 本物のライブラリで「元が同じ画像の組を探す…」を選び、元が同じ組が見つかり、違う画像が組に入りすぎないかを見る。まとめる操作はしない（利用者だけが確かめる）

### そのほか（FR-108、FR-606、FR-608、6章）

- [ ] 人物の写真をダブルクリックで拡大表示すると、帯の倍率のスライダーの左に「骨格を重ねる」が出る。押すと、白い線と点が関節の位置に重なって出る。2人以上写っていれば全員に出る
- [ ] 骨格を出したまま ⌘＋で拡大し、ドラッグで動かしても、骨格が関節に重なったまま動く。左右キーで次の人物の写真へ移っても出たまま。人物のいない画像では「骨格を重ねる」が出ない
- [ ] 試し用のライブラリのカテゴリのフォルダに、対応していない形式のファイル（`.mp4` など）を2つ置いて ↻ を押す。スキップの一覧の「対応していない形式のファイルを _未対応ファイル/ へ移す（2件）」を押すと、ライブラリの直下の `_未対応ファイル/` へ移り、行が「対応していない形式なので、_未対応ファイル/ へ移しました」に変わる。次に ↻ を押しても一覧に出ない（FR-108）
- [ ] 設定の「一般」で「差分検出で、対応していない形式のファイルを _未対応ファイル/ へ移す」をオンにし、`.mov` などを置いて ↻ を押すと、自動で `_未対応ファイル/` へ移り、スキップの一覧に移したと出る。オンのまま、ライブラリの外のフォルダを取り込むと、対応していない形式のファイルはスキップされるだけで移らない。Kura を起動し直してもオンのまま
- [ ] デスクトップに、ライブラリの画像の1枚を縮小した写し（プレビューで「サイズを調整」）を作り、Finder から検索欄の右の「画像で探す」へドラッグする。ドラッグの間はボタンに枠が付き、上に来ると地がグレーになる。落とすと結果の帯の基準にその画像が出て、元の画像が先頭のほうに来る
- [ ] 「画像で探す」を押して、ファイル選択からライブラリの外の画像を選んでも、同じく結果が出る。探した後、一覧の枚数が変わらず、その画像はライブラリに入っていない
- [ ] 2枚の画像、フォルダ、テキストファイルを「画像で探す」に落とすと、探さずにステータスバーに理由が出る。一覧のほかの場所に画像を落とすと、今までどおり取り込む
- [ ] 1枚を選んで ⇧⌘F を押すか「ファイル」→「似た画像を探す」を選ぶと、詳細パネルの「似た画像を探す」と同じ結果のモードになる。検索欄に入力している間は ⇧⌘F が効かない
