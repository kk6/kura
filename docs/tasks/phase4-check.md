## A. 作った機能の手直し（4a、タスク #10）

完了条件：一覧と拡大表示の右クリックから主な操作ができ、管理情報を Finder を使わずに戻せる。

### 右クリックメニュー（FR-515、FR-712）

- [ ] 一覧で画像を右クリックすると、詳細パネルで行える操作（ゴミ箱に移動、Finder で表示、似た画像を探す、ボードに追加…など）が出る
- [ ] 拡大表示で右クリックすると、一覧と同じメニューが出る。「画像をダウンロード」「共有」などの標準のメニューは出ない
- [ ] メニューの各項目を押すと、詳細パネルのボタンと同じ結果になる
- [ ] 複数の画像を選んで右クリックすると、選んだ画像すべてに効く
- [ ] 「ボードに追加…」で一度追加した後、メニューに「「<ボード名>」に追加」が出る。押すとダイアログなしでそのボードに追加される
- [ ] そのボードを消すと「「<ボード名>」に追加」が出なくなる。アイデアボードを OFF にしている間も出ない
- [ ] ゴミ箱と「見つからない」の画像では、その画面で行える操作だけが出る

### ボードへのドラッグ（FR-713）

- [ ] 一覧の画像1枚を、開いているボードのウィンドウへドラッグすると、落とした位置に置かれる
- [ ] 複数の画像を選んでドラッグすると、まとめて置かれる
- [ ] ボードで ⌘Z を押すと、ドラッグで足した分がまとめて消える
- [ ] ボードのウィンドウの外で離すと、何も起きない
- [ ] ボードを閉じて開き直すと、ドラッグで足した画像が残っている

### 絞り込み（FR-516、FR-517）

- [ ] サイドバーの「カテゴリ」の見出しのスイッチで子カテゴリを含めないにすると、カテゴリを押したときにそのカテゴリの直下の画像だけが出る。カテゴリの件数も直下の分になる
- [ ] スイッチを戻すと、子カテゴリの画像も出て、件数も戻る
- [ ] アプリを起動し直しても、スイッチの状態が残る
- [ ] タグを ⌥ を押しながら押すと、名前に取り消し線が付き、そのタグの付いた画像が一覧から消える。もう一度 ⌥ で押すと戻る
- [ ] カテゴリも ⌥ を押しながら押すと、そのカテゴリの画像が除かれる
- [ ] タグを選びながら別のタグを除くと、両方の条件を満たす画像だけが出る
- [ ] 除いた結果から画像を複数選び、まとめてタグを付けられる
- [ ] 類似画像検索の結果でも、⌥ でタグやカテゴリを除ける
- [ ] 2万枚のライブラリで、除く絞り込みを変えても結果がすぐに出る（0.5秒以内）

### 管理情報を戻す（FR-107）

試し用のライブラリで行う。

- [ ] 設定の「管理情報を書き出す…」で書き出し、その後にタグを付け替え、画像をカテゴリ間で移す
- [ ] 設定の「管理情報を戻す…」で書き出したファイルを選ぶと、確認ダイアログに書き出した日時と、両方の画像の枚数が出る
- [ ] 戻すと、ライブラリが開き直り、タグが書き出したときの状態に戻る。移した画像は、差分検出で今の場所に反映される
- [ ] `.kura/backups/` に `kura-before-restore-<日時>.db` ができている
- [ ] その写しを「管理情報を戻す…」で選ぶと、戻す前の状態に戻せる
- [ ] ボードを開いたまま戻すと、ボードが保存されて閉じ、戻した後に開き直すと戻した管理情報のボードが出る
- [ ] 特徴量の計算中に戻しても、戻した後に計算が続き、計算済みの画像を計算し直さない
- [ ] 取り込みの途中で戻そうとすると、断られる
- [ ] 別のライブラリで書き出した管理情報を選ぶと、「別のライブラリの管理情報かもしれません」と警告が出る。やめると何も変わらない
- [ ] 管理情報でないファイル（画像など）を選ぶと、エラーが出て、今の管理情報は変わらない

### 設定のページと拡大表示（8章）

- [ ] ⌘, と歯車のアイコンで、一覧の場所に設定のページが出る。サイドバーは残る
- [ ] 「閉じる」と Escape で一覧に戻る
- [ ] 前の設定ダイアログにあった操作が、すべてページで行える
- [ ] ON/OFF の項目がスイッチになっていて、切り替えると前と同じように効く
- [ ] 拡大表示の「閉じる」が、画像の上で目立ちすぎず、押せる

## B. 類似画像検索の拡張（4b、タスク #19）

完了条件：元が同じ画像の組を、1枚を残してゴミ箱に移せる。タスク #11 で決めたことに合わせて直してから確かめる。

### 重複の整理（FR-610、FR-611）

試し用のライブラリに、見本の写真を縮小・トリミング・色味を変えた組を入れて行う。

- [ ] 類似画像検索の結果から元が同じ画像を選び、1枚を残してほかをゴミ箱に移せる
- [ ] 移す前に、残す画像のカテゴリとタグを確かめて変えられる
- [ ] ゴミ箱に移した画像を、ゴミ箱から元に戻せる
- [ ] ライブラリ全体から元が同じ画像の組が一覧に出て、組ごとに同じ操作で整理できる
- [ ] 本物のライブラリで、元が同じ組が見つかり、違う画像が組に入りすぎない（利用者だけが確かめる）

### そのほか（FR-606、FR-607、FR-608、10章）

- [ ] 文章で探すと、内容に合う画像が上に来る（タスク #11 で作ると決めた場合）
- [ ] ギャラリー外の画像をドロップすると、それに似た画像が出る。ドロップした画像はライブラリに入らない
