### 右クリックメニュー（FR-515、FR-712）

- [x] 一覧で画像を右クリックすると、詳細パネルで行える操作（ゴミ箱に移動、Finder で表示、似た画像を探す、ボードに追加…など）が出る
- [x] 拡大表示で右クリックすると、一覧と同じメニューが出る。「画像をダウンロード」「共有」などの標準のメニューは出ない
- [x] メニューの各項目を押すと、詳細パネルのボタンと同じ結果になる
- [x] 複数の画像を選んで右クリックすると、選んだ画像すべてに効く
- [x] 「ボードに追加…」で一度追加した後、メニューに「「<ボード名>」に追加」が出る。押すとダイアログなしでそのボードに追加される
- [x] そのボードを消すと「「<ボード名>」に追加」が出なくなる。アイデアボードを OFF にしている間も出ない
- [x] ゴミ箱と「見つからない」の画像では、その画面で行える操作だけが出る

### ボードへのドラッグ（FR-713）

- [x] 一覧の画像1枚を、開いているボードのウィンドウへドラッグすると、落とした位置に置かれる
- [x] 複数の画像を選んでドラッグすると、まとめて置かれる
- [x] ボードで ⌘Z を押すと、ドラッグで足した分がまとめて消える
- [x] ボードのウィンドウの外で離すと、何も起きない
- [x] ボードを閉じて開き直すと、ドラッグで足した画像が残っている

### 絞り込み（FR-516、FR-517）

- [x] サイドバーの「カテゴリ」の見出しのスイッチで子カテゴリを含めないにすると、カテゴリを押したときにそのカテゴリの直下の画像だけが出る。カテゴリの件数も直下の分になる
- [x] スイッチを戻すと、子カテゴリの画像も出て、件数も戻る
- [x] アプリを起動し直しても、スイッチの状態が残る
- [x] タグを ⌥ を押しながら押すと、名前に取り消し線が付き、そのタグの付いた画像が一覧から消える。もう一度 ⌥ で押すと戻る
- [x] カテゴリも ⌥ を押しながら押すと、そのカテゴリの画像が除かれる
- [x] タグを選びながら別のタグを除くと、両方の条件を満たす画像だけが出る
- [x] 除いた結果から画像を複数選び、まとめてタグを付けられる

- [x] 2万枚のライブラリで、除く絞り込みを変えても結果がすぐに出る（0.5秒以内）
