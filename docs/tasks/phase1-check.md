# フェーズ1の通しの確認（タスク #20）

利用者が、最初のリリース（v0.1.0）の前に通しで確かめる手順です。手順は `docs/user-guide.md` の順に並べています。終わった項目に `x` を付けてください。動きがおかしい項目は、項目の下に何が起きたかを書いてください。

## 準備

- リリース用のビルドで `.app` を作る：`npm run tauri build`（`src-tauri/target/release/bundle/macos/Kura.app` にできる）。`npm run tauri dev` は取り込みがとても遅いので使わない
- 確認は2つのライブラリで行う
  - **A：本物の資料のライブラリ**。新しく作った空のライブラリに、本物の資料を取り込む。元のフォルダは変わらない（取り込みはコピーする）。名前の変更、移動、削除など、ファイルを動かす操作はここでは試さない
  - **B：試し用のライブラリ**。`npm run dev-library -- 300` で作った `dev-library/` を、新しく作った空のライブラリに取り込む。ファイルを動かす操作はここで試す
- A と B の行き来：メニューバーの「ファイル」→「ライブラリを切り替える…」（⇧⌘O）でライブラリ選択画面に戻る。もう一方は「最近使ったライブラリ」から開く。B を作るときは、A を開いたまま切り替えて「新しいライブラリを作る」を押す

## A. 本物の資料（タスク #20 の完了条件）

### ライブラリと取り込み

- [ ] 「新しいライブラリを作る」で空のフォルダを選び、ライブラリができる
- [ ] 中身のあるフォルダを選ぶと「空のフォルダを選んでください」と出る
- [ ] 「フォルダを取り込む」で本物の資料のフォルダを選ぶと、サブフォルダがカテゴリになって取り込まれる
- [ ] 取り込みの間、ステータスバーに進み具合が出て、ヘッダーのボタンの代わりに「取り込み中…」が出る
- [ ] 終わると「完了：取り込み N枚」が出る。スキップがあれば「注意：スキップ N枚」を押して、一覧の理由が正しい
- [ ] 取り込んだ枚数が、元のフォルダの画像の枚数（重複と対応していない形式を除く）と合う
- [ ] 元の資料フォルダの中身が変わっていない
- [ ] 取り込みの途中で ⇧⌘O を押すと、「ライブラリを切り替えられません」のダイアログが出て、取り込みが続く
- [ ] 詳細パネルのメモに入力したまま ⇧⌘O を押すと、選択画面に戻る。「最近使ったライブラリ」の先頭に A があり、押して開き直すと、入力したメモが残っている

### 見る・探す

- [ ] 一覧が引っかからずにスクロールできる
- [ ] 並べ替え（取り込み日、ファイル名、評価、ランダム）が効く
- [ ] スライダーでサムネイルの大きさが変わり、アプリを起動し直しても残る
- [ ] 画像を押すと詳細パネルに情報が出る。ダブルクリックか Space で拡大表示になり、左右キーで前後に移れる
- [ ] 何枚かの画像にタグを付ける（1枚ずつと、複数を選んでまとめて）
- [ ] サイドバーのタグを押すと、そのタグの画像だけが出る。⌘ を押しながら別のタグを押すと、AND と OR で結果が変わる
- [ ] タグを押した後の Escape と、サイドバーの余白を押すことで、タグの選択が外れる
- [ ] 検索欄（⌘F）でファイル名、メモ、タグ名、カテゴリ名を探せる
- [ ] カテゴリを押すと、子カテゴリの画像も出る。サイドバーの件数が合っている

## B. 試し用のライブラリ（ファイルを動かす操作）

### カテゴリ

- [ ] ＋でカテゴリを作れる。同じ名前を入れると、入力欄の下にエラーが出る
- [ ] ダブルクリックでカテゴリ名を変えると、Finder でもフォルダ名が変わる
- [ ] カテゴリを別のカテゴリへドラッグすると、確認の後に移り、Finder でもフォルダが移る
- [ ] 詳細パネルで画像のカテゴリを変えると、Finder でもファイルが移る
- [ ] カテゴリを削除すると、中の画像が未分類に移る

### 画像

- [ ] 詳細パネルでファイル名を変えると、Finder でもファイル名が変わる
- [ ] 評価とメモを付け、別の画像を選んでから戻っても残っている
- [ ] 「ゴミ箱へ移す」（⌘Delete）で一覧から消え、「ゴミ箱」に出る
- [ ] ゴミ箱で「元に戻す」と、元のカテゴリに戻り、タグとメモも残っている
- [ ] 「完全に削除」と「ゴミ箱を空にする」で、確認の後に消える

### タグ管理

- [ ] タグの名前を変えられる。ほかのタグと同じ名前にはできない
- [ ] 統合すると、元のタグが付いていた画像に統合先のタグが付く
- [ ] 削除すると、すべての画像からタグが外れる

### Finder で変えたとき

Kura を開いたまま Finder で次のことをして、サイドバーの ↻ を押す。

- [ ] 画像を別のカテゴリのフォルダへ移すと、カテゴリが変わり、タグが残る
- [ ] 画像をライブラリの外へ移すと、「見つからない」に出る。元に戻して ↻ を押すと、一覧に戻る
- [ ] カテゴリのフォルダの名前を変えると、新しい名前のカテゴリになり、画像のタグが残る
- [ ] ライブラリの外から画像を入れると、登録される

### 設定とバックアップ

- [ ] 歯車のアイコンか ⌘, で設定が開く
- [ ] 「管理情報を書き出す…」で書き出せる
- [ ] ユーザーガイドの「バックアップから戻す」の手順で戻せる

### 困ったとき

- [ ] ライブラリのフォルダの名前を Finder で変えてから Kura を起動すると、「エラー：ライブラリが見つかりません」と出て、ライブラリ選択画面に戻る。「ライブラリを開く」で選び直せる
