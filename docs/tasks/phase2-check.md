## A. 入口とボード管理（タスク #1〜#5、#16）

- [ ] 初めての設定でも既存版からの更新でも初期ON。起動しただけではボードは開かない

- [ ] ボードがないときは「ボードを作成」が出て、開いただけでは作成されない
- [ ] 新規作成の名前は「新しいボード」、使用済みなら番号付き。名前を変えても、そのままでも作れる
- [ ] 空白だけ・101文字以上・NFCや大文字小文字の違いだけの重複はエラー。1文字・100文字・`/` を含む名前は使える。別ライブラリの同名は許可される
- [ ] 上部でボードを作成・切り替え・名前変更できる。切り替えても以前の内容が残る
- [ ] 開くボタンや⌘Bを繰り返してもウィンドウは1つ。閉じて開くと、そのライブラリで最後に使ったボードが開く
- [ ] ボードの削除では名前・配置件数と元画像を消さない説明が出る。キャンセルで残り、削除後も元画像はギャラリーに残る
- [ ] 削除後はボード選択画面、最後の1つを削除したら「ボードを作成」になる。削除したボードはUndoで戻らない
- [ ] 見つからないダミーライブラリに「一覧から外す」が出る。確認なしで履歴から消え、フォルダとDBは変わらない。再び「ライブラリを開く」で選べる。一時的に外しただけでは自動で消えない

## G. 元画像との連動（タスク #12）

タスク12（`feat/phase2-image-lifecycle`）は、元画像の今の状態を参照 ID で引くこと（名前変更・ゴミ箱・復元・完全削除、古いライブラリの要求の拒否）をRustテストで確かめた。完全削除後に画像が復活しないこと、ID の再利用と再取り込みで結び直さないことは、タスク1のRustテストが確かめている。開いたままのボードで枠になる・戻ること、枠の移動と外す操作、枠では加工できないこと、取り消しで前の状態の画像を出さないこと、「ギャラリーで表示」の有効・無効、ギャラリー側の絞り込みの解除・選択・スクロール・ゴミ箱と見つからない一覧での選択を、モックのe2e（`e2e/board-lifecycle.spec.ts`）で確かめた。隔離したデバッグ版の実アプリ（run `i-lifecycle-2`）では、ボードを開いたまま1枚の画像について、ゴミ箱へ移すと「ゴミ箱にあります」の枠になり元に戻すと同じ位置に画像が戻ること、ライブラリの外へ移して差分を確認すると「見つからない」の枠になり別のカテゴリのフォルダへ戻して再確認すると画像が戻ること、完全に削除すると「削除された画像」と名前の枠になり Delete で外せること、枠では加工の項目が押せず回転のハンドルが出ないこと、「ギャラリーで表示」がゴミ箱・見つからない・すべての画像の各一覧でその画像を選びボードは閉じないことを確かめた。2枚以上での確認、名前変更とカテゴリ移動、再取り込み、ダイアログを開いている間の「ギャラリーで表示」、最前面固定を外した状態でメインウィンドウが手前に出る見え方は実アプリで未確認。デバッグ版での確認でリリース用ビルドではないため、Gのチェック欄は未確認のままにする。

すべてダミー画像で行う。ボードを開いたまま、ギャラリーまたはFinder側で変更する。

- [ ] 名前変更とカテゴリ移動後も同じ画像が表示され、再表示しても参照が切れない
- [ ] ゴミ箱へ移すと「ゴミ箱にあります」の枠になり、復元すると加工・位置・大きさを保って戻る
- [ ] Finderで外へ移して差分検出すると「見つからない」の枠になり、元へ戻して再検出すると復元する
- [ ] 完全削除後は「削除された画像」と削除前の名前が残り、画像・サムネイルが残らない。「見つからない」登録の削除でも同じになる
- [ ] 同じ画像を取り込み直しても削除済み枠には自動で結び付かない。枠はDeleteで外せる
- [ ] 完全削除と編集の保存・Undoが重なっても、画像が復活したり別画像になったりしない（タスク12のテスト証跡も確認）
- [ ] 「ギャラリーで表示」で通常・ゴミ箱・見つからないの各一覧へ移り、対象が選択されて見える。通常画像では絞り込みが解除される。ボードは閉じない。完全削除済みの枠では操作できない

## H. 元URL（タスク #13〜#15）

タスク13・14（`feat/phase2-source-url`）は、拡張属性の読み取り（binary／XML の plist、記録なし、解析できない、文字列でない項目、一方だけ有効、HTTP/S 以外、2番目が空、3件以上、属性を読めない）、通常取り込みと差分検出での保存、重複・移動で既存の元URLを変えないこと、元URLを保存できないときは画像も登録しないこと、開くURLの選び方をRustテストで、ステータスバーの「元URLの注意」と一覧、詳細パネルのリンク・「なし」・開けない値・開く失敗の表示をモックのe2eで確かめた。隔離したデバッグ版の実アプリ（run `j-source-url-1`）では、属性をテストの中で付けたダミー画像12枚を通常取り込みし、11枚の登録・重複1枚のスキップ・「元URLの注意 5件」とその対象、DB の値、詳細パネルの表示が全ケースで合うことを確かめた。Finder 追加に当たる差分検出でも2枚の登録と注意1件を確かめ、同じ中身に別の記録を付けた重複では既存の元URLが変わらなかった。リンクを押すと、既定のブラウザがローカルの確認用ページ（127.0.0.1）を読みに来た。実アプリで開く処理を失敗させる確認と、本物のブラウザのダウンロードで付いた属性での確認はしていない。デバッグ版での確認でリリース用ビルドではないため、Hのチェック欄は未確認のままにする。

- [ ] 元URLの拡張属性をテスト用に付けた画像を通常取り込みとFinder追加→差分検出の両方で登録し、1番目が画像URL、2番目が掲載ページURLになる
- [ ] 記録なしでも取り込める。不正な記録でも画像の取り込みは成功し、注意の件数と対象が分かる。一方が有効ならその値は保存される。3番目以降を使わない
- [ ] 同じ画像の重複取り込みで既存URLが変わらない。元URL取得のためのネットワーク通信はない
- [ ] 詳細では掲載ページURLを優先し、なければ画像URL、どちらもなければ「なし」。押すと確認なしで既定のブラウザが開く
- [ ] 不正な値とHTTP/S以外は開かない。開く処理の失敗時に詳細パネルのエラーが見える（隔離環境の失敗テストで確認）
- [ ] 設定の「元URLを補完」で既存画像の未登録分を補完できる。既存の値は片方だけ登録されている場合も上書きしない。元フォルダを探さない
- [ ] 補完・記録なし・失敗・対象外（ゴミ箱／見つからない）の件数と進み具合が分かる。中断後も補完済みは残り、再実行できる
- [ ] 補完中は閲覧・検索・ボード編集ができる。取り込み・差分検出・ファイル変更（カテゴリ経由を含む）・ライブラリ切り替えは待つ。取り込み・差分検出中は補完を開始できない

## I. メニュー・入力・回帰（タスク #17）

タスク17（`claude/phase2-integration-3d60fa`）は、メニューの「編集」の「取り消す」「やり直す」「すべてを選択」を自前の項目にし、Rust が手前のウィンドウへ送って画面が同じショートカットのキーとして扱う形にした（入力欄では文字に効かせる）。「ボードに追加…」は、ギャラリーが手前で追加できる画像を選び、ダイアログを開いていないときだけ有効にした。ギャラリーでダイアログを開いている間は、ボードの最前面の固定を外す。ほかに、低いウィンドウで右クリックのメニューが切れる件と、差分確認で戻った「見つからない」の画像の選択が空の一覧に残る件を直した。モックの e2e（`e2e/edit-menu.spec.ts`、`e2e/board-lifecycle.spec.ts`、`e2e/gallery.spec.ts`）で、メニューからのイベントが配置・一覧・入力欄の文字に効くこと、ダイアログの開閉を Rust に知らせること、メニューがウィンドウに収まることを確かめた。隔離したデバッグ版の実アプリ（run `l-menu-2`）では、「ボードに追加…」が選択なし・ダイアログ中・ボードが手前のときに押せず、選択ありのギャラリーで押せること、メニューの「すべてを選択」がギャラリーの一覧とボードの配置に効くこと、ボードでキーの ⌘Z が1回だけ取り消し（DB の配置で確認）、メニューの「やり直す」で戻ること、ボードの ⌘A がギャラリーの選択を変えないこと、検索欄でキーとメニューの ⌘A・⌘Z・⇧⌘Z が文字に1回だけ効くこと、固定中にギャラリーの設定を開くとボードのウィンドウの層が 5 から 0 になり、閉じると 5 に戻ることを確かめた。確認ダイアログでの固定の解除、Shift を押しながらの15°刻みの回転、Dock からの終了、補完の途中の待ちは確かめていない。リリース用ビルドではないため、Iのチェック欄は未確認のままにする。

- [ ] ウインドウ→アイデアボード（⌘B）、ファイル→ボードに追加（⇧⌘B）、編集→Undo/Redo（⌘Z／⇧⌘Z）、ボード上の全選択（⌘A）が働く
- [ ] 追加はギャラリーが手前で追加可能な画像を選択した場合だけ有効。ウィンドウを行き来しても別の画面に操作が漏れない
- [ ] 文字入力中のUndo/Redo・全選択は文字だけに作用する。Space、Delete等も入力を壊さない。ダイアログ中に背後の配置を変更しない
- [ ] OFFでも通常の文字編集と既存ギャラリーのショートカットは使える
- [ ] ギャラリーの選択・検索・タグ・メモ・カテゴリ・取り込み・ゴミ箱が従来どおり使える。ギャラリー側の範囲選択や直接ドロップ追加が紛れ込んでいない
