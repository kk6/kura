## A. ON/OFF とモデルの取得（タスク #2、#3）

- [ ] 初めての設定でも既存版からの更新でも、初期値は OFF。OFF の間は「似た画像を探す」がどこにも出ず、ワーカーのプロセスも動いていない
- [ ] 起動しただけ、設定を開いただけでは通信しない
- [ ] ON にすると、モデルの大きさを見せる確認が出る。キャンセルすると OFF のままで、通信もしない
- [ ] 確認して進めるとダウンロードが始まり、進み具合が分かる。終わると ON になる
- [ ] ネットワークを切った状態や途中で切れた状態では、エラーと「再試行」が出て、ON にならない。つなぎ直して「再試行」すると ON になる
- [ ] OFF に戻すと入口が消える。もう一度 ON にしても、ダウンロードし直さず、計算済みの特徴量も残っている
- [ ] モデルがそろった後は、ネットワークを切っても計算と検索ができる（NFR-09）
- [ ] uv も Python も入っていない環境と同じ条件（`PATH` を絞る）で起動しても動く

## B. 特徴量の計算（タスク #4、#5）

- [ ] ON にすると、開いているライブラリの計算が自動で始まり、ステータスバーに「特徴量を計算中 N / M枚」が出る
- [ ] 計算中も、一覧のスクロール、絞り込み、タグ付け、取り込み、差分の確認、カテゴリの移動、ゴミ箱、ボードの編集ができる。どれも計算の終わりを待たない
- [ ] 新しく取り込んだ画像と、Finder で足して差分の確認で登録した画像が、後から計算される
- [ ] 計算の途中でアプリを終了しても、待たされずに終わる。次に開くと続きから計算する
- [ ] 計算の途中でライブラリを切り替えると、次のライブラリの計算が始まる。戻ると続きから計算する。2つのライブラリの特徴量が混ざらない
- [ ] 設定で計算状況（済み・残り・計算できなかった枚数）が分かる。「再計算」で計算し直せる
- [ ] ゴミ箱と「見つからない」画像は計算されない
- [ ] `.kura/features.db` ができ、`kura.db` の大きさはほとんど変わらない。画像のファイルとその更新日時は変わらない

## C. 似た画像を探す（タスク #6、#7）

- [ ] 1枚を選ぶと、詳細パネルと右クリックメニューに「似た画像を探す」が出る。複数選択、ゴミ箱、「見つからない」画像では使えない
- [ ] 未計算の画像では押せず、理由が出る
- [ ] 押すと、一覧が類似度の高い順になる。帯に基準画像と「閉じる」が出て、並べ替えの選択欄は出ない。基準画像が先頭にある
- [ ] 見分けやすい写真のライブラリで、似た内容の組の相手が上のほうに出る
- [ ] 未計算の画像が残っているときは結果に出ず、「未計算 N枚」と分かる
- [ ] 結果の中で、選択・詳細・拡大表示（左右キーは結果の並び順）・タグ付け・メモが通常どおり使える
- [ ] 結果の画像から「似た画像を探す」を押すと、基準が入れ替わる
- [ ] 「閉じる」と Escape（選択も拡大表示もないとき）で、元の並びとスクロールの位置に戻る
- [ ] ボードの配置からは探せない。「ギャラリーで表示」で移ってから探せる

## D. 重み（タスク #8）

- [ ] 帯に「内容」と「構図」のスライダーがあり、初めは同じ値になっている
- [ ] 動かしている間も、並びが追従して変わる
- [ ] 「構図」を0にすると内容の似た画像が、「内容」を0にすると構図の似た画像が上に来る。似た構図で内容が違う組で確かめる
- [ ] 両方を0にはできない
- [ ] 重みは、検索を閉じても、ライブラリを切り替えても、再起動しても残る

## E. 結果の絞り込み（タスク #7）

- [ ] 結果を、サイドバーのカテゴリとタグ（AND/OR）、検索バーで絞れる。絞っても類似度の順のまま
- [ ] ステータスバーの「出ている枚数 / 全体の枚数」が合っている
- [ ] 絞り込みを外すと、結果の全体に戻る。検索を閉じると、絞り込みは通常の一覧にそのまま効いている

## F. 既存の操作との連動（タスク #4、#5）

- [ ] 基準画像や結果の画像の名前変更・カテゴリの変更をしても、計算し直さずに結果に出る
- [ ] 結果の画像をゴミ箱へ移すと結果から消える。元に戻すと、計算し直さずに結果に出る
- [ ] ゴミ箱で完全に削除した画像と、「一覧から外す」で外した画像の特徴量が `features.db` から消える
- [ ] Finder で中身を差し替えた画像（同じ場所、別の中身）は、差分の確認の後に新しい中身で計算し直される
- [ ] 設定の「管理情報を書き出す…」で書き出した DB に特徴量は入らない。書き出した DB へ戻して開くと、残っている `features.db` がそのまま使われ、足りない分だけ計算される
- [ ] `features.db` を消して開いても、エラーにならず、計算し直される
