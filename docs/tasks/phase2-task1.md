## 保存するデータ

DBをバージョン7から8へ移行し、`boards`、`board_items`、`board_sources`、`board_state` を追加した。既存の移行は変更していない。定義は [library.rs](../../src-tauri/src/library.rs) にある。

- ボードは名前、表示位置、倍率、更新日時、保存revisionを持つ。
- 配置は画像と独立したID、枠の寸法、位置、倍率、回転、反転、グレースケール、トリミング、重なり順を持つ。同じ画像を複数配置できる。
- 画像参照は再利用しないIDを持つ。画像の登録時に作り、名前や寸法の変更を追跡し、完全削除時は画像への参照を切って最後の名前と寸法を残す。画像の数値IDが再利用されても古い参照は結び直さない。
- 配置を外したときは非表示の行としてIDと画像参照の組を保持する。Undoで同じ配置を戻せる。ボード削除時は、そのボードの非表示の配置も消す。画像ファイルは変更しない。
- 最後のボードはライブラリごとに保存する。そのボードを削除したら空にする。これらの追加情報は既存のSQLiteバックアップに含まれる。

## Rust APIの契約

入口は [board.rs](../../src-tauri/src/board.rs)。`Access::with` のライブラリロック内で呼ぶ。要求が持つライブラリトークンを、DB操作の前に同じロック内で検査する。

| 関数 | 動作 |
| --- | --- |
| `session` | 今回ライブラリを開いたときのトークンを取得する |
| `list`、`last`、`load` | 一覧と配置件数、最後のボード、指定ボードを読む |
| `sources` | 追加する画像IDから、Rustが管理する画像参照を取得する。ゴミ箱・見つからない画像は追加できない |
| `create` | 名前と初期スナップショットを1トランザクションで作り、編集トークンと採番済みの配置を返す |
| `open` | 最後のボードを更新し、新しい編集トークンを発行する。前の編集トークンは失効する |
| `rename`、`delete` | 名前を変更する、またはボードとその配置だけを削除する |
| `save` | 編集トークン、revision、配置と視点のスナップショットを検査し、一括保存する。成功応答にトークンと保存revisionを返す |

`Snapshot` は `Viewport` と `ItemDraft` の配列。新しい配置は `id: None` とし、返された配置IDを以後の保存とUndoで保持する。既存配置のボードと画像参照は差し替えられない。元画像の名前・寸法・状態は入力を信頼せず、RustがDBから返す。

`Geometry.width` と `height` は倍率を適用する前の枠の寸法。トリミングは反転・回転前の元画像に対する0〜1の矩形で、未指定は元画像全体を表す。重なり順は `stack_order`、同値なら配置IDの順に読む。

ライブラリトークンは開くたびに変わるため、A→B→Aでも古い要求は使えない。revisionは前回保存した値より大きくする。失敗ではrevisionを消費せず、同じrevisionで再試行できる。成功済みrevisionの再送は拒否する。応答を失った場合は、読み直して保存状態を確認する必要がある。画面側の保存キュー、応答の照合、閉じる際の編集トークンの失効は後続タスクで実装する。

名前は前後の空白を除き、NFCにそろえた1〜100文字。重複は同じライブラリ内でNFCと大小文字をそろえて判定する。`/` などの記号は許す。数値は有限値、寸法と倍率は正数、トリミングは元画像の範囲内に限る。
