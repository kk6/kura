# Kura デザインの決まり

Kura の画面は、白・黒・グレーの3色を基本にして作ります。主役は参考画像で、UIは画像の邪魔をしないことを最優先にします。色を使うのは、エラー・警告・完了・お知らせの4つの状態を示すときだけです。

元になるプロトタイプ：[Kura UIプロトタイプ v2](https://claude.ai/artifact/TQHrYLpADNMWU6VaNTgKXL)

フェーズ2の前に、利用者が AI と作ったリニューアル案（画像）をもとに、文字と余白を大きくし、配置を変えた（2026-11-07、利用者と決めた）。原則と「使わないもの」は変えず、トークンの値と部品だけを変えた。案の画像は AI の生成物なのでリポジトリに入れていない。機能の変更は `docs/requirements.md` の 5.5 にある。

## 1. 原則

1. 色は白・黒・グレーだけを使う。差し色は使わない。例外は、エラー・警告・完了・お知らせの状態を示す4色（「3. 部品ごとの決まり」の「状態の表示」）と、画像の中身の色（同じく「画像の中身の色」）だけとする。
2. 画像を並べる部分の地は、色みのないグレーにする。地に色が付いていると、参考画像の色が実際と違って見えるため。
3. 選択中の状態は、黒い枠かグレーの背景で示す。色の違いで示さない。
4. 情報は詰めて表示する。余白で見た目を整えるより、一度に見える画像の数を優先する。
5. 下の「デザイントークン」にない色や数値は使わない。新しい値が必要になったら、先にこのファイルに追加する。

## 2. デザイントークン

CSS変数として `src/styles/tokens.css` に定義し、コンポーネントからは変数だけを参照します。

### 色

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--color-bg` | `#F3F3F1` | 画像を並べる部分の地 |

### 動き

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--duration-spin` | `1s` | 処理中のアイコンが1回転する時間 |
| `--duration-fast` | `120ms` | マウスを乗せたとき・押したときの背景と大きさの変化 |
| `--duration-base` | `160ms` | ダイアログが開くときの動き |
| `--duration-panel` | `240ms` | 詳細パネルが滑り込む・滑り出る動き |
| `--motion-press` | `0.96` | 押している間のボタンの縮み（`scale` の値） |
| `--motion-rise` | `4px` | ダイアログが開くときに下から上がる距離 |

緩急はどれも `ease-out`（始めが速く、終わりがゆっくり）にする。押した手応えをすぐ返すため。

## 3. 部品ごとの決まり

- **選択中の画像**：`2px` の `--color-text` の枠を付け、その内側に `1px` の `--color-bg` の線を入れる。画像が暗くても明るくても見分けられるようにするため。
  - 左上に、`--size-check` の四角のチェックの印を重ねる。地を `--color-text`、チェックを `--color-on-text` の線、角丸を `--radius-sm` にし、枠の内側から `--space-2` 離す。枠だけでは選択中かが見分けにくかったため（2026-11-07 に利用者と決めた）
  - 印は表示するだけで、押しても何も起きない。選んでいない画像には、マウスを乗せても出さない
- **画面の配置**：ギャラリー画面は、ヘッダー、サイドバー、一覧、詳細パネル、ステータスバーで作る（2026-11-07 のリニューアル）
  - ヘッダー：左にアプリのアイコンと「Kura」、その下にライブラリ名と ▾（押すとライブラリのメニュー）。中央に検索欄を置き、欄の右端に「⌘F」と出す。右に取り込みのボタン2つ、主要ボタン「アイデアボード」（フェーズ2、ON の間だけ）、設定
  - サイドバー：「ライブラリ」（すべての画像、未分類、ゴミ箱、見つからない）、「カテゴリ」、「タグ」の見出しで分ける。見出しの文字は `--font-size-md` の太字。「ライブラリ」の項目とカテゴリの行には線のアイコンを付ける。「タグ」の見出しは押すと一覧を閉じる・開くので、文字の右に開閉の印（カテゴリの行と同じ山形）を付ける。下端に境界線を引き、ライブラリの場所（パスは途中を「…」で省き、全体は `title` で出す）を置く
  - 一覧の上の帯：高さ `--size-toolbar`、地は `--color-surface`。左に見出し（`--font-size-xl` の太字）と枚数、右に並べ替え、スライダー、詳細パネルを開閉するボタン
  - 詳細パネル：上に見出し「画像の詳細」と閉じる × を置く。項目の見出し（カテゴリ、タグ、メモなど）はラベルの列ではなく、値の上に置く
  - ステータスバー：左に枚数と選んでいる枚数を「・」で区切って出す。取り込みの結果などはその右に出す
- **選択中のカテゴリ・オンのトグル**：背景を `--color-selected` にし、文字を太字にする。
- **主要なボタン**：1画面に1つだけにする。地を `--color-text`、文字を `--color-on-text` にする。ギャラリー画面では、画像を追加せず専用ウィンドウを開く「アイデアボード」がこれにあたる。「ボードに追加」は詳細パネルの通常ボタンとし、主要ボタンにしない。アイデアボードはフェーズ2で作るので、フェーズ1のギャラリー画面には主要なボタンを置かない。フェーズ2以降も、設定でアイデアボードを OFF にしたときは、関連するボタンとメニューを表示しない（FR-711）。ダイアログは1つの画面と数え、実行のボタン（「削除する」「移す」「統合する」など）を主要なボタンにする。「閉じる」だけのダイアログには置かない。押せないときは、地を `--color-raise`、枠線と文字を `--border` と `--color-text-faint` にする。
- **その他のボタン**：地を `--color-surface`、枠線を `--border` にする。
- **押せないボタン**：文字を `--color-text-faint`、枠線を `--color-raise` にする。押せるボタンと文字の色だけで見分けるのは難しいため、枠線も薄くする。
- **リンク**：色で区別できないので、下線を付ける。
- **やめるボタンの文言**：ダイアログで操作をやめるボタンは「キャンセル」にそろえる。「閉じる」は、何も実行しないダイアログ（一覧や設定）を閉じるときだけに使う。
- **スクロールバー**：OS の初期の見た目を使わない。幅 `--size-scrollbar`、溝は透明、つまみは `--color-line` で、角丸を `--radius-md` にする。マウスを乗せたつまみだけ `--color-text-faint` にする。初期の灰色の太いバーは、画像の横で目立ちすぎたため（2026-11-07 に利用者と決めた）
- **スライダー**：OS の初期の見た目を使わない。溝は高さ `--size-progress` の `--color-line` の線、つまみは `--size-slider-thumb` の四角で、地を `--color-text`、角丸を `--radius-sm` にする。
- **ダイアログ**：幅 `--size-dialog`。地を `--color-surface`、枠線を `--border`、角丸を `--radius-md` にする。影と背後の暗い幕は付けない。
- **アイコン**：線で描くアイコン（線の太さ 1.8〜2px、大きさ 14〜15px）に統一する。アイコンだけのボタンには `aria-label` を付ける。
  - 絵は [Lucide](https://lucide.dev/)（ISC ライセンス）から、使うものの path だけを `src/icons.tsx` に写す。依存は足さない
  - 文字のボタンは、文字の前にアイコンを付ける（アイコンと文字）。アイコンだけで意味が伝わり、置く場所の狭い「設定」は、アイコンだけにして `aria-label` と `title` で名前を出す。ボタンの表示形式を設定で切り替える機能は作らない（2026-11-06 に利用者と決めた）。アイデアボードの ON/OFF（FR-711）による関連操作の表示・非表示は、この表示形式の設定とは別に扱う
  - アイコンを付けるのは、ヘッダーの「画像を取り込む」「フォルダを取り込む」「設定」、一覧の上の帯の詳細パネルを開閉するボタン、詳細パネルの「Finderで表示」「ゴミ箱へ移す」と閉じる ×、ゴミ箱と見つからない画像のパネルのボタン、サイドバーの「ライブラリ」の項目とカテゴリの行、ライブラリの場所。ダイアログの中のボタン（「キャンセル」「閉じる」と実行のボタン）は文字だけにする
- **動き**：押した手応えを返すための短い動きだけを使う（2026-11-06 に利用者と決めた）。例外は詳細パネルの開閉だけにする（2026-11-09 に利用者と決めた）
  - ボタン：マウスを乗せると背景を `--color-raise` に、押している間は背景を `--color-selected` にして `--motion-press` まで縮める。主要なボタンは背景を変えず、縮めるだけにする。押せないボタンは変えない
  - サイドバーの押せる行：マウスを乗せると背景を `--color-raise` に、押している間は `--color-selected` にする。行は幅いっぱいで、縮めると周りがずれて見えるので縮めない。選択中の行は背景を変えない
  - サイドバーの小さなボタン（AND と OR、＋などのアイコン）：押している間は `--motion-press` まで縮める
  - 変化にはどれも `--duration-fast` をかける
  - ダイアログ：開くときに、`--duration-base` で透明から現れながら `--motion-rise` だけ下から上がる。閉じるときは動かさない
  - 詳細パネル：開くときは、先に一覧を1回だけ並べ直して場所を空け、パネルが `--duration-panel` で右から滑り込む。閉じるときは、パネルが `--duration-panel` で右へ滑り出てから、一覧を1回だけ並べ直す。列の幅はなめらかに変えない。幅を変え続けると、一覧が毎フレーム並べ直してサムネイルが跳ねるため。滑り出る間のパネルは、フォーカスもクリックも受けない
  - 画像を並べる部分（一覧のサムネイル、拡大表示）と詳細パネルのプレビューには動きを足さない。画像の見え方を邪魔しないため
  - 動きを減らす設定（`prefers-reduced-motion`）では、どの動きも止める（背景の色の変化は、時間をかけずに切り替える）
- **処理中の表示**：押せないボタンを残さず、ボタンの場所に回る円弧のアイコン（線のアイコン）と「取り込み中…」のような文言を出す。押せない理由がわからないと、壊れたと思われるため。ボタンは見えないまま場所を残し、周りの部品が動かないようにする。動きを減らす設定（`prefers-reduced-motion`）では回さない。今はヘッダーの取り込みのボタンだけに使う（取り込みと差分検出の間）
- **進み具合のバー**：高さ `--size-progress`。地を `--color-line`、進んだ部分を `--color-text` にする。
- **状態の表示**：エラー・警告・完了・お知らせは、色・アイコンの形・先頭の言葉の3つで区別する。色の見分けにくい環境や読み上げでも区別できるようにするため。

  | 状態 | 色 | アイコン | 先頭の言葉 |
  | --- | --- | --- | --- |
  | エラー | `--color-error` | 丸に× | 「エラー：」 |
  | 警告 | `--color-warning` | 三角に！ | 「注意：」 |
  | 完了 | `--color-success` | 丸にチェック | 「完了：」 |
  | お知らせ | `--color-info` | 丸に i | 「お知らせ：」 |

  - 色は文字、線のアイコン、入力欄の枠だけに使う。背景の塗りつぶしには使わない。大きな色の面があると、隣の参考画像の色の見え方が変わるため
  - 画像を並べる部分（ギャラリーの地、拡大表示、アイデアボードのキャンバス）の中には置かない
  - 出す場所は内容で分ける

    | 内容 | 出す場所 | 例 |
    | --- | --- | --- |
    | 入力のエラー | 入力欄のすぐ下に文言を出し、入力欄の枠を 2px の `--color-error` にする。この入力欄にはフォーカスの枠を重ねない（枠が 4px の二重になるため。文字のカーソルで選ばれていることがわかる） | 「エラー：同じ名前のカテゴリがあります」 |
    | 一括操作の結果 | ステータスバーに要約を出す。クリックで一覧のダイアログを開く | 「完了：取り込み 480枚」「注意：スキップ 12枚」 |
    | 取り消せない操作の確認 | ダイアログ | カテゴリの削除、ゴミ箱を空にする |
    | 続けられないエラー | ダイアログ。またはライブラリ選択画面に文言を出す | 「エラー：ライブラリが見つかりません」 |

  - 一定時間で消える通知（トースト）は使わない。取り込み結果のように後で見返したい内容を見逃すため
- **画像の中身の色**：画像から計算した色は、UIの色ではなく画像の内容なので、白・黒・グレーの決まりの対象外とする。トークンにも入れず、DB の値をそのまま使う。次の2つがこれにあたる
  - サムネイルを読み込むまでの塗りつぶし（代表色。`docs/requirements.md` の5.5）
  - 詳細パネルの主要な8色の見本（FR-802、フェーズ5）。四角い見本を並べ、角丸を `--radius-sm`、枠線を `--border` にする。地に近い白やグレーの見本も見分けられるようにするため。見本の大きさのトークンは、作るときにこのファイルへ足す
  - 画像の中身の色を、状態の表示、選択中の目印、ボタンなどのUIの色に使わない

- **アプリのアイコン**：明るいグレーの角丸の四角の上に、`--color-text` の太い直線で、屋根と2本の柱、その間の横線2本（蔵の棚）を描く（2026-11-07 に利用者と決めた。案 A「開いた蔵」）。`src-tauri/icons/icon.svg` を元にし、`npx tauri icon` で各サイズを作る。角丸の四角の形は macOS のアイコンのテンプレートに合わせるので、下の「角丸 4px を超える大きな角丸」の対象外とする。ヘッダーのロゴにも同じ絵を線のアイコンとして使う

### アイデアボードと元URL（フェーズ2）

2026-11-08 に利用者と決めた。動作と保存の正本は `docs/requirements.md` の5.2・5.7・6章。

- ギャラリーの入口「アイデアボード」と選択画像を送る「ボードに追加」を分ける。詳細パネルの追加ボタンは1枚・複数選択のどちらでも置く。右クリックメニューと「ファイル」メニューからも同じ追加ダイアログを開く
- 追加ダイアログは追加先の選択欄、新規作成時の名前欄、「キャンセル」「追加」で構成する。「追加」だけを主要ボタンにする。確定前にはボードを作らない
- ボードの上部は `--size-board-toolbar` と `--color-surface` を基本にする。現在のボードの選択欄、「新しいボード」、管理メニュー（名前を変更・削除）、「全体を表示」「選択画像を表示」、「最前面に固定」、不透明度スライダーと「100%に戻す」を置く。狭いウィンドウでも操作が隠れて到達不能にならないようにする
- キャンバスの地は `--color-board`。選択枠とハンドルは既存の白黒のトークンを使う。1枚・複数のどちらも四隅のハンドルで縦横比を保って拡大・縮小する。回転とトリミングの操作対象は1枚だけにする
- 重なり順と「ギャラリーで表示」は画像の右クリックメニューに置く。最前面へ送る操作とウィンドウの「最前面に固定」を文言で区別する
- ボードがないときは「ボードを作成」を表示する。作成・名前変更のダイアログには入力欄と実行ボタンを置き、名前のエラーは入力欄の下に出す。削除確認にはボード名・配置件数と、元画像は削除されないことを明記する
- 「ゴミ箱にあります」「見つからない」「削除された画像」は、キャンバス上の配置の枠内に白黒の文言で表示する。完全削除後は削除前のファイル名を残す。画像やサムネイルを代わりに出さない。キャンバス内に状態色を持ち込まない
- 保存状態はキャンバスの外の状態表示領域に「保存中」「保存済み」「保存できませんでした」と出す。失敗時には「再試行」を置き、状態色を使う場合は既存の「状態の表示」に従う。一時的なトーストにしない
- ボードの ON/OFF と「元URLを補完」は設定ダイアログに置く。OFF で保存待ちの間は切り替え処理中と分かる表示にし、失敗時は ON に残してエラーを出す
- 元URLは下線付きリンクとし、掲載ページURLを優先する。開けない値はリンクにしない。開く処理の失敗は詳細パネルに表示する
- 元URLの取得結果はステータスバーに件数を出し、注意から対象の一覧を見られるようにする。補完では進み具合・中断操作・結果を表示し、補完済み、記録なし、失敗、対象外を区別する。補完中も設定を閉じて閲覧・ボード編集ができ、設定を開き直して進捗確認・中断ができるようにする
- ライブラリ選択画面の見つからない項目には「一覧から外す」を置く。フォルダを消す操作と誤解されない文言にする
- 新しい画面の文字ボタンにも既存の線アイコンの規則を適用する。ダイアログ内のボタンは既存どおり文字だけにする。必要なサイズのトークンは実装時にこの文書と `tokens.css` に同時に追加する

## 4. 使わないもの

- 白・黒・グレー以外の色（差し色を含む）。例外は「状態の表示」の4色と「画像の中身の色」だけ
- グラデーション
- 影（選択枠の内側の線を除く）
- 半透明やぼかしを使ったガラス風の表現。作画中の参照のために利用者が指定する、ボードウィンドウ全体の不透明度（FR-707）は別の機能として許可する
- 角丸 4px を超える大きな角丸
- 絵文字のアイコン
- 左端だけに色の付いた線を引いたカード
- UIライブラリの初期スタイルをそのまま使うこと（部品の動きだけ使い、見た目はトークンで上書きする）

## 5. 未定のこと

- ダークモード（初回リリースの対象外）。
- カテゴリの色（FR-413）。利用者が選んだカテゴリの色を、状態の4色と画像の中身の色に並ぶ3つ目の例外にする予定。色の数と値、使う場所（カテゴリ名の前の印だけにするか）は、作るときにここへ書く。
