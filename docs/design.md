# Kura デザインの決まり

Kura の画面は、白・黒・グレーの3色を基本にして作ります。主役は参考画像で、UIは画像の邪魔をしないことを最優先にします。色を使うのは、エラー・警告・完了・お知らせの4つの状態を示すときだけです。

元になるプロトタイプ：[Kura UIプロトタイプ v2](https://claude.ai/artifact/TQHrYLpADNMWU6VaNTgKXL)

## 1. 原則

1. 色は白・黒・グレーだけを使う。差し色は使わない。例外は、エラー・警告・完了・お知らせの状態を示す4色だけとする（「3. 部品ごとの決まり」の「状態の表示」）。
2. 画像を並べる部分の地は、色みのないグレーにする。地に色が付いていると、参考画像の色が実際と違って見えるため。
3. 選択中の状態は、黒い枠かグレーの背景で示す。色の違いで示さない。
4. 情報は詰めて表示する。余白で見た目を整えるより、一度に見える画像の数を優先する。
5. 下の「デザイントークン」にない色や数値は使わない。新しい値が必要になったら、先にこのファイルに追加する。

## 2. デザイントークン

CSS変数として `src/styles/tokens.css` に定義し、コンポーネントからは変数だけを参照します。

### 色

| 変数 | 値 | 使う場所 |
| --- | --- | --- |
| `--color-bg` | `#F3F3F1` | 画像を並べる部分の地 |
| `--color-surface` | `#FAFAF9` | ヘッダー、サイドバー、詳細パネル、ステータスバーの地 |
| `--color-input` | `#FFFFFF` | 入力欄の地 |
| `--color-raise` | `#ECECE9` | 押されているボタン、プレビューの枠の地 |
| `--color-selected` | `#E6E6E2` | 選択中のカテゴリ、オンになっているトグルの背景 |
| `--color-line` | `#DCDCD8` | 境界線、入力欄やボタンの枠線 |
| `--color-text` | `#1C1C1A` | 本文の文字、選択中の画像の枠、主要なボタンの地 |
| `--color-text-sub` | `#55554F` | 補足の文字、アイコン |
| `--color-text-faint` | `#6A6A64` | 件数、ラベル、見出しの小さな文字 |
| `--color-on-text` | `#FAFAF9` | 黒い地の上の文字 |
| `--color-board` | `#E6E6E3` | お絵描きモードのキャンバスの地 |
| `--color-error` | `#B42318` | エラーの文言、アイコン、入力欄の枠 |
| `--color-warning` | `#8A5300` | 警告の文言、アイコン |
| `--color-success` | `#18703A` | 完了の文言、アイコン |
| `--color-info` | `#1F5FB0` | お知らせの文言、アイコン |

文字色はすべて、背景に対してコントラスト比 4.5:1 以上になる組み合わせで使います。`--color-text-faint` は `--color-bg` の上でも 4.5:1 を超えます。状態の4色は、`--color-surface`、`--color-input`、`--color-bg` の上で 4.5:1 を超えます（`--color-surface` の上で、エラー 6.29、警告 6.06、完了 5.88、お知らせ 6.05）。警告は黄色だと白地で読めないため、暗い黄土色にしています。

## 3. 部品ごとの決まり

- **選択中の画像**：`2px` の `--color-text` の枠を付け、その内側に `1px` の `--color-bg` の線を入れる。画像が暗くても明るくても見分けられるようにするため。
- **選択中のカテゴリ・オンのトグル**：背景を `--color-selected` にし、文字を太字にする。
- **主要なボタン**：1画面に1つだけにする。地を `--color-text`、文字を `--color-on-text` にする。ギャラリー画面では「お絵描きモード」がこれにあたる。
- **その他のボタン**：地を `--color-surface`、枠線を `--border` にする。
- **リンク**：色で区別できないので、下線を付ける。
- **アイコン**：線で描くアイコン（線の太さ 1.8〜2px、大きさ 14〜15px）に統一する。アイコンだけのボタンには `aria-label` を付ける。
- **進み具合のバー**：高さ 3px。地を `--color-line`、進んだ部分を `--color-text` にする。
- **状態の表示**：エラー・警告・完了・お知らせは、色・アイコンの形・先頭の言葉の3つで区別する。色の見分けにくい環境や読み上げでも区別できるようにするため。

  | 状態 | 色 | アイコン | 先頭の言葉 |
  | --- | --- | --- | --- |
  | エラー | `--color-error` | 丸に× | 「エラー：」 |
  | 警告 | `--color-warning` | 三角に！ | 「注意：」 |
  | 完了 | `--color-success` | 丸にチェック | 「完了：」 |
  | お知らせ | `--color-info` | 丸に i | 「お知らせ：」 |

  - 色は文字、線のアイコン、入力欄の枠だけに使う。背景の塗りつぶしには使わない。大きな色の面があると、隣の参考画像の色の見え方が変わるため
  - 画像を並べる部分（ギャラリーの地、拡大表示、お絵描きモードのキャンバス）の中には置かない
  - 出す場所は内容で分ける

    | 内容 | 出す場所 | 例 |
    | --- | --- | --- |
    | 入力のエラー | 入力欄のすぐ下に文言を出し、入力欄の枠を 2px の `--color-error` にする | 「エラー：同じ名前のカテゴリがあります」 |
    | 一括操作の結果 | ステータスバーに要約を出す。クリックで一覧のダイアログを開く | 「完了：取り込み 480枚」「注意：スキップ 12枚」 |
    | 取り消せない操作の確認 | ダイアログ | カテゴリの削除、ゴミ箱を空にする |
    | 続けられないエラー | ダイアログ。またはライブラリ選択画面に文言を出す | 「エラー：ライブラリが見つかりません」 |

  - 一定時間で消える通知（トースト）は使わない。取り込み結果のように後で見返したい内容を見逃すため

## 4. 使わないもの

- 白・黒・グレー以外の色（差し色を含む）。例外は「状態の表示」の4色だけ
- グラデーション
- 影（選択枠の内側の線を除く）
- 半透明やぼかしを使ったガラス風の表現
- 角丸 4px を超える大きな角丸
- 絵文字のアイコン
- 左端だけに色の付いた線を引いたカード
- UIライブラリの初期スタイルをそのまま使うこと（部品の動きだけ使い、見た目はトークンで上書きする）
