# ADR-0003: ワーカーは計算する画像があるときだけ起動し、落ちても自動で起動し直さない

## Status

accepted

## Date

2026-11-15

## Context (Why)

類似画像の検索そのものは Rust だけで行い、ワーカーを使わない。ワーカーはモデルを読み込むので、動かしている間はその分のメモリを使う。スパイクの時点では、アプリの起動中ずっとワーカーを動かす方針だった。

## Intent (What)

- ワーカーは、特徴量を計算する画像があるときだけ起動し、未計算の画像がなくなったら終わらせる
- ワーカーは標準入力が閉じると終わる。アプリがどう終わっても、ワーカーのプロセスは残らない
- ワーカーが落ちたとき、または30秒返事がないときは、そのとき計算していた1枚を「計算できなかった画像」に数え、計算を止めてエラーを出す。自動では起動し直さない
- 計算を再開するのは、ライブラリを開いた後、取り込みと差分検出の後、類似画像検索を ON にしたとき、設定の「再計算」を押したときだけにする

## Constraints

- 計算できなかった画像の記録はメモリの中だけに持つ。アプリを起動し直すと、その画像をもう一度試す

## Alternatives Considered

- **アプリの起動中ずっとワーカーを動かす**（スパイクの時点の方針）：検索に使わないモデルの分のメモリを使い続けるので却下した
- **落ちたら自動で起動し直す**：同じ画像で落ち続けるおそれがあるので却下した

## Consequences

- 計算が終われば、ワーカーの分のメモリは解放される
- 計算を始めるたびに、ワーカーの起動とモデルの読み込みの時間がかかる
- ワーカーが落ちると、次のきっかけまで計算が止まる。利用者は設定の「再計算」で再開する
