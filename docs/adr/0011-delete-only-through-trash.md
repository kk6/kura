# ADR-0011: 画像の完全削除は、ゴミ箱を通してだけ行う

## Status

accepted

## Date

2026-11-05

## Context (Why)

画像を削除すると、アプリ内のゴミ箱に入る（FR-511）。ゴミ箱の中の一部の画像だけを消したいこともある。フェーズ1のタスク16の確認の後に、利用者と決めた。

## Intent (What)

- ゴミ箱の画面で、選んだ画像だけを完全に削除できる。取り消せないので、枚数を見せて確認する。消し方はゴミ箱を空にするときと同じ
- ゴミ箱を通さずにすぐ削除する操作は作らない

## Alternatives Considered

- **ゴミ箱を通さずにすぐ削除する操作**：ふだんの削除が取り消せなくなるおそれがあるので却下した

## Consequences

- 画像を完全に消すには、ゴミ箱へ移してからゴミ箱で消す2つの手順が要る
- ふだんの削除は、ゴミ箱を空にするまで元に戻せる
