# ADR-0031: DB のバックアップは書き出しだけを作り、戻す操作は作らない

## Status

superseded by [ADR-0032](0032-restore-backup-in-app.md)

## Date

2026-11-05

## Context (Why)

利用者は、ライブラリの管理情報（DB）をバックアップできる必要がある（NFR-07）。フェーズ1のタスク18で、利用者と決めた。

## Intent (What)

- 設定ダイアログの「管理情報を書き出す…」で、保存先を選んで DB を1つのファイルに書き出す。画像ファイルとサムネイルは含まない
- ライブラリを開いたまま、WAL に残った変更も含めて、整った写しを書き出す
- 途中で失敗しても、保存先にあった前のファイルを壊さない
- 戻すときは、利用者が手順に沿って `kura.db` を置き換える。手順は `docs/requirements.md` の6章にある

## Non-goals

- アプリの中で戻す操作

## Alternatives Considered

- **戻す操作も作る**：フェーズ1では書き出しだけにした

## Consequences

- 戻すには、アプリを終了してファイルを手で置き換える必要がある
- 書き出した後に動かした画像は、戻した後の差分検出（FR-104）が反映するか、「見つからない」画像として知らせる
