# ADR-0029: 自動のタグ付けは、推定したタグを候補として出し、承認したものだけを付ける

## Status

accepted

## Date

2026-11-07

## Context (Why)

手作業のタグ付けに手間がかかったので、利用者から、画像の中身からタグを推定する機能の要望があった（FR-609）。推定は誤ることがある。タグは絞り込み（FR-504）に使う。

## Intent (What)

- 推定したタグは候補として出し、利用者が承認するまで画像のタグにしない
- 推定はタグのグループ（FR-409 のポーズ、アングル、部位など）ごとに分けて扱えるようにする
- ワーカーは推定結果を返すだけにし、DB への書き込みは Rust が行う（[ADR-0001](0001-desktop-app-with-tauri.md)）
- 手法は、作るときに実際の画像で試して決める（`docs/requirements.md` の10章）

## Alternatives Considered

- **推定したタグをそのまま付ける**：誤ったタグが絞り込みに混ざると、手で付けたタグも信用できなくなるので却下した
- **物体検出の YOLO を主役にする**：学習済みの分類（COCO）に服の種類や部位がないので、主役にしない
- 手法の候補として、画像埋め込みのゼロショット、イラストのタグで学習した分類器（WD14 タガーなど）、写真の部位を検出するモデル（NudeNet など）、ローカルの画像言語モデルを残している。比べるのは作るとき

## Consequences

- 候補と承認済みのタグを、DB で分けて持つ必要がある（持ち方は未決）
