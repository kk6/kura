# ADR-0023: アイデアボードを、本体に同梱する任意の機能にする

## Status

accepted

## Date

2026-11-08

## Context (Why)

アイデアボード（5.7）は、作画中に参考画像を並べて参照するための画面である。使わない利用者や、使わない起動もある。フェーズ2の開始前に、利用者と範囲を決めた。

## Intent (What)

- 名称は「アイデアボード」にする
- 本体に同梱し、設定で ON/OFF を切り替える（FR-711）。初期値は ON。OFF にしても保存済みのボードは残す
- 画面は開くときに読み込み、使わない起動時には読み込まない
- フェーズ2では FR-701〜FR-708 と FR-711 を作る。自動整列（FR-709）はフェーズ4、直接追加（FR-710）はフェーズ4の候補に残す

## Non-goals

- プラグインのインストールや更新の仕組み
- 作品管理・バーチャル見本誌（`docs/future-ideas.md`）のための共通基盤や拡張ポイント

## Alternatives Considered

- **プラグインとして別に入れる**：インストールや更新の仕組みを作らずに済むよう、本体に同梱した

## Consequences

- アイデアボードを使わない利用者も、ボードのコードを含むアプリを入れる
- OFF のときは関連のボタン・メニュー・ショートカットを隠す必要がある
