# ADR-0002: 機械学習の処理を別プロセスのワーカーにし、onedir の形で同梱する

## Status

accepted

## Date

2026-11-15

## Context (Why)

類似画像検索（5.6）の特徴量は、Python の機械学習のライブラリで計算する。利用者に uv や Python を入れてもらう前提にはしたくない。アプリの外部への通信は NFR-08 の範囲に限る。フェーズ1の前のスパイク（`spikes/tauri-python/`）で、Tauri から Python のワーカーを起動する方法を比べた。

## Intent (What)

- 特徴量の計算は、アプリ本体と別のプロセス（ワーカー）で行う。モデルを入れ替えても本体のコードを変えなくてよい（NFR-11）
- ワーカーは `.app` に同梱する。利用者は uv も Python もインストールしなくてよい
- ワーカーの起動は速くする。スパイクでは onedir の起動が約0.04秒だった
- ワーカーが落ちたときと返事がないときの動きを、偽のワーカーを起動するテストで確かめられる

## Constraints

- 同梱物のために外部への通信を増やさない（NFR-08）
- ワーカーは画像を読んで特徴量を返すだけにする。ファイルも DB も変えない（[ADR-0001](0001-desktop-app-with-tauri.md)）

## Alternatives Considered

- **単一ファイルの形（PyInstaller の onefile、Tauri のサイドカー）**：起動のたびに展開するので、起動に約0.85秒かかった。onedir は約0.04秒だった
- **スパイクで使った `tauri-plugin-shell` で起動する**：クレートが1つ増える。Rust の標準のプロセス起動で足り、偽のワーカーでテストしやすいので使わない
- **起動時に Python の実行環境をダウンロードする**：外部への通信が増える（NFR-08）ので却下した

## Consequences

- 利用者は追加のインストールなしで類似画像検索を使える
- `.app` が大きくなる。ワーカーは onedir で112MB だった（`spikes/similarity/README.md`）
- リリースのビルドの前に、ワーカーのビルドが要る
