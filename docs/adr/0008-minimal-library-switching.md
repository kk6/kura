# ADR-0008: 複数のライブラリの切り替えを最小限で足す

## Status

accepted

## Date

2026-11-06

## Context (Why)

フェーズ1の通しの確認（タスク #20）で、本物の資料と試し用の2つのライブラリを行き来する必要があった。FR-105 は Could で、本来は後のフェーズの機能だった。外付けドライブに置いたライブラリは、一時的に見つからないことがある。

## Intent (What)

- 2026-11-06：最初のリリース（v0.1.0）の前に、ライブラリ選択画面へ戻る最小限の切り替えを足す（利用者と決めた）
- 2026-11-07：UI のリニューアルで、ヘッダーのライブラリ名のメニューから、選択画面を通らずに最近使ったライブラリへ切り替えられるようにする（利用者と決めた）
- 2026-11-08：フェーズ2の FR-105 は、既存の切り替えに、ボードと入力中のメモの保存完了を待つ処理を足すところまでとする。保存に失敗したら切り替えを中止する（利用者と決めた）
- 2026-11-08：見つからないライブラリを「最近使ったライブラリ」から外す操作（FR-106）をフェーズ2に入れる。外すのは利用者の操作だけで、自動では外さない（利用者と決めた。要望は 2026-11-06）
- 一度に開けるライブラリは1つにする

## Non-goals

- 複数のライブラリの同時表示
- ライブラリ間での画像やボードの移動・コピー
- 選択画面の「キャンセル」

## Alternatives Considered

- **見つからないライブラリを一覧から自動で外す**：外付けドライブが一時的に外れているだけのことがあるので却下した
- **フェーズ4まで待つ**：通しの確認で2つのライブラリを行き来する必要があったので、最小限だけを先に足した

## Consequences

- 本物のライブラリと試し用のライブラリを、アプリを起動し直さずに行き来できる
- 種類の違うライブラリを同時に開く使い方（フェーズ5）は、別に決める必要がある（`docs/requirements.md` の10章）
