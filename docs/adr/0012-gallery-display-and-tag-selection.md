# ADR-0012: 一覧はメイソンリー型だけにし、サイドバーのタグは押すたびに選ぶ・外すを切り替える

## Status

accepted

## Date

2026-11-14

## Context (Why)

一覧とサイドバーの見た目と操作は、フェーズ1の後に何度か見直した。

- 2026-11-06：フェーズ1の確認の後、サイドバーのタグを、一覧の画像と同じ選び方（修飾キーなしで押すとそれだけを選ぶ）に変えた
- 2026-11-07：フェーズ2の前の UI のリニューアルで、一覧の上の帯、詳細パネルの開閉、選んだ画像のチェックの印などを足した
- 2026-11-14：0.3.0 の後、タグが増えてサイドバーのスクロールが長くなった。画面の外で選ばれたままのタグに気づかずにカテゴリを押すと、絞り込みの結果を不具合と誤解しやすかった

## Intent (What)

- 一覧の表示形式はメイソンリー型だけにする（2026-11-07、利用者と決めた）
- 選んだ画像には、黒い枠に加えて左上にチェックの印を重ねる（2026-11-07、利用者と決めた）
- サイドバーの「タグ」の見出しでタグ一覧を閉じられる。閉じている間も、選んでいるタグは出す（2026-11-07、利用者と決めた）
- サイドバーのタグは、詳細パネルのタグと同じ四角い部品を折り返して並べ、件数を出す。選んでいるタグは先頭へ寄せる（2026-11-14、利用者と決めた）
- サイドバーのタグは、修飾キーなしで押すたびに、選ぶ・外すが切り替わる（2026-11-14、利用者と決めた）。マウスだけで複数のタグを選べる。Shift の範囲選択は一覧の画像と同じ選び方のまま残す
- タグの AND と OR は、つまみが選んだ側へ滑るスイッチにする（2026-11-14、利用者と決めた）

## Non-goals

- 正方形に切り抜くグリッド型（FR-502）
- サイドバーのタグの表示の切り替え（FR-414）
- リニューアルの案にあった「すべて／画像」のタブ、ステータスバーの寸法表示、2つ目のスライダー

## Alternatives Considered

- **グリッド型との切り替え（FR-502）**：作らないと決めた（2026-11-07）。一覧はメイソンリー型だけにする
- **黒い枠だけで選択を示す**：選択中かが見分けにくかったので、チェックの印を足した
- **タグを1行に1つ並べ、表示を切り替える（FR-414）**：件数付きで折り返す表示1つにしたので、FR-414 は取り下げた
- **修飾キーなしで押すと、そのタグだけを選ぶ**（2026-11-06 の選び方）：複数のタグをマウスだけで選べず、押して入れたり切ったりする四角い部品の見た目とも合わないので、切り替えに戻した

## Consequences

- 別のタグ1つへ移るときは、Escape か余白で外してから押す
- 見た目の決まりは `docs/design.md` にある
