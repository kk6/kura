# ADR-0027: DB を移行する前に、移行前の `kura.db` の写しを残す

## Status

accepted

## Date

2026-11-09

## Context (Why)

DB にはスキーマの版を持たせ、後のフェーズでテーブルを足すときに、既存のライブラリを移行する。移行した後は、古い版のアプリでライブラリを開けなくなる。

## Intent (What)

- DB を移行するときは、最初の移行の前に、移行前の `kura.db` の写しを `.kura/backups/` に書く（2026-11-09、利用者と決めた）
- 写しを書けなければ移行せず、ライブラリを開かずにエラーにする
- 写しは消さずにすべて残す。要らなければ利用者が手で消す
- 作ったばかりのライブラリ（版0）と、移行の要らないライブラリでは写しを作らない

## Alternatives Considered

- **写しを作らずに移行する**：移行した後に戻す先がなくなるので却下した
- **古い写しを自動で消す**：移行は版を上げるときだけなので、写しの数は増えにくい。消さずに残すことにした

## Consequences

- 移行のたびに、ライブラリの `.kura/backups/` に写しが1つ増える
- 開発版が本物のライブラリを開くと、移行して写しが残る（[ADR-0028](0028-two-settings-locations.md)）
