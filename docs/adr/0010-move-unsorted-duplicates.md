# ADR-0010: 未分類にある重複画像は、スキップせずに取り込み先のカテゴリへ移す

## Status

accepted

## Date

2026-11-05

## Context (Why)

利用者は、カテゴリを削除して画像を未分類へ移した後で、同じ構成のフォルダを取り込み直すことがある。重複（FR-204）としてスキップするだけだと、カテゴリだけができて、画像は未分類に残る。フェーズ1のタスク16の確認の後に分かった。

## Intent (What)

- 取り込み先がカテゴリで、同じ中身の画像が未分類にあれば、スキップせずにその画像を取り込み先のカテゴリへ移す。ファイルも移す（[ADR-0005](0005-crash-safe-file-move.md) の手順）。タグとメモはそのまま残る
- 同じ画像が別のカテゴリかゴミ箱にあれば、これまでどおり重複としてスキップする
- 移した枚数は、取り込んだ枚数とは別にステータスバーに出す

## Constraints

- 利用者が整理した場所（未分類以外のカテゴリ）を、取り込みで変えない

## Alternatives Considered

- **すべての重複をスキップする**：カテゴリを作り直した後で取り込み直すと、画像が未分類に残るので却下した
- **別のカテゴリにある重複も取り込み先へ移す**：利用者が整理した場所を取り込みで変えてしまうので却下した

## Consequences

- カテゴリを作り直す使い方で、画像がそのカテゴリに戻る
- 差分検出（FR-104）にはこの例外を使わない。ファイルはすでにライブラリの中にあり、利用者が置いた場所を変えないため
