# ADR-0013: 追加した日での絞り込みには、登録日時を使う

## Status

accepted

## Date

2026-11-05

## Context (Why)

利用者は、X などからまとめて保存した画像を一度に取り込み、後日その日に取り込んだ画像をカテゴリ分けやタグ付けすることがある（FR-505）。ローカルから取り込んだ画像の取り込み日時は、元ファイルの更新日時になる（FR-203）。

## Intent (What)

- 追加した日での絞り込みは、登録日時（アプリに追加した時刻）を使う
- 開始日と終了日で範囲を指定する。どちらか一方だけでもよい。日付は入力欄に打つほか、カレンダーからも選べる
- 作るのはフェーズ4のまま

## Alternatives Considered

- **取り込み日時を使う**：ローカルから取り込んだ画像では元ファイルの更新日時なので、まとめて取り込んだ日と一致しないことがある。そのため却下した

## Consequences

- 画像は、並べ替えに使う取り込み日時と、絞り込みに使う登録日時の2つの日時を持つ
