# ADR-0020: モデルは同梱せず、利用者が類似画像検索を ON にしたときにダウンロードする

## Status

accepted

## Date

2026-11-15

## Context (Why)

類似画像検索のモデルは数百MB ある。アプリ自身が通信するのは、URL 取り込みと、初回のモデルのダウンロードだけにする（NFR-08）。外部サービスの都合でモデルが消えても、取得できなくなるのは避けたい。

## Intent (What)

- 類似画像検索は、設定の「類似画像検索を使う」で ON にする。初期値は OFF
- ON にすると、モデルの大きさを見せて確認してからダウンロードする。利用者が押すまで通信しない。モデルがそろっていても確認は毎回出し、そろっているときは通信せずに ON にする（2026-11-15、利用者と決めた）
- モデルはアプリのデータフォルダに置き、ライブラリの中には置かない
- 内容のモデル（SigLIP 2）は、Kura の GitHub Release に置いた写しから取得し、SHA-256 で確かめる。ライセンスの写しと著作権表示を同じ Release に置き、README と設定の説明の下にも1行で書く（2026-11-16、利用者と決めた）
- ポーズのモデル（YOLOX-tiny と RTMPose-m）は写しを置かず、OpenMMLab の公式の配布先から zip のまま取得し、zip と取り出したファイルの両方を SHA-256 で確かめる（2026-11-18、利用者が決めた）
- 3a で ON にしていた利用者が更新したときは、足したポーズのモデル（約75MB）を、設定から押して取得してもらう。それまで内容と構図の計算と検索は続ける（2026-11-18、利用者が決めた）
- 通信が止まったら失敗にする。30秒つながらないか、毎秒1KB未満が60秒続いたら、エラーと「再試行」を出す。全体の時間では打ち切らない（2026-11-15、利用者と決めた）
- OFF に戻しても、モデルと計算済みの特徴量は消さない

## Non-goals

- 途中からのダウンロードの再開

## Constraints

- NFR-08：利用者が押すまで通信しない
- モデルのライセンスが再配布を認めているときだけ、写しを置く

## Alternatives Considered

- **モデルを `.app` に同梱する**：リリースの zip が毎回数百MB増えるので却下した
- **元の配布先から取得する（内容のモデル）**：外部サービスの都合でモデルが消えると困るので、Kura の Release に写しを置いた。SigLIP 2 は Apache-2.0 で、写しと表示を添えれば再配布できる
- **ポーズのモデルも写しを置く**：配布物にライセンスの表記がなく、学習データ（Human-Art など）に非商用の条件がある。Kura が再配布してよいと判断できなかったので却下した。調べた根拠は `docs/tasks/phase3-design.md` の5章
- **HTTP のクレートを足してダウンロードする**：macOS に入っている `/usr/bin/curl` を Rust から起動する。進み具合は書きかけのファイルの大きさから出す（2026-11-15、利用者と決めた）
- **全体の時間で打ち切る**：遅い回線でも、進んでいる間は止めないため却下した
- **3a から更新した利用者のポーズのモデルを自動で取得する**：利用者が押すまで通信しない決まり（NFR-08）に反するので却下した

## Consequences

- アプリの zip は小さいまま保てる
- 公式の配布先が消えると、ポーズのモデルを取得できなくなる。このことは受け入れる
- モデルを差し替えるときは、新しいタグの Release に置き、`ml/model.json` を直す（CLAUDE.md の「モデルのリリース」）
