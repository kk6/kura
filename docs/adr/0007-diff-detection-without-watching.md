# ADR-0007: Finder での変更は常時監視せず、差分検出で反映する

## Status

accepted

## Date

2026-11-05

## Context (Why)

利用者は Finder でもライブラリのファイルを動かす。アプリは、DB と実際のファイルの差（追加・削除・移動）を反映する必要がある（FR-104）。外付けドライブは一時的に外れたり、不調になったりする。

## Intent (What)

- 差分の検出は、起動時（ライブラリを開いた後）と利用者の手動の操作のときに行う。ファイルを常時監視しない
- カテゴリのフォルダがなくなった（Finder で削除・名前変更・移動した）ときは、カテゴリを子孫ごと消す。中の画像のうち、同じハッシュのファイルが別の場所にあるものは移動として扱う。残りの画像は未分類にして「見つからない」にする（2026-11-05、利用者と決めた。A）
- 「フォルダがない」と判断するのは、そのフォルダを調べて NotFound になったときだけにする。権限などで読めないだけのときは、カテゴリも画像も変えずにエラーとして知らせる
- 同じ場所のファイルの中身が変わったときは、同じ画像として行を更新し、タグとメモを残す。新しい中身が別の画像と同じなら、更新せずに重複として知らせる（2026-11-05、利用者と決めた。B）

## Constraints

- 外付けドライブの一時的な不調で、カテゴリや画像の状態をまとめて変えない
- 差分検出はファイルを動かさず、DB とサムネイルだけを変える

## Alternatives Considered

- **ファイルを常時監視する**：アプリ自身の移動や名前変更でも監視のイベントが届く。Finder の操作と見分ける処理と、そのテストが難しくなるので却下した
- **見つからないファイルの行を消す**：タグやメモを失うので、行を残して「見つからない」状態にした
- **中身が変わったファイルを、別の新しい画像として登録し直す**：タグとメモを失うので却下した

## Consequences

- Finder での変更は、起動するか「差分を確認」を押すまで反映されない
- 差分検出の途中も一覧を操作できるよう、1枚ごとにロックを外して進み具合を出す
