# ADR-0025: 画像以外の資料は、種類ごとに別のライブラリで管理する

## Status

accepted

## Date

2026-11-04

## Context (Why)

フェーズ5では、画像以外の資料（CLIP STUDIO PAINT の .clip、フォント、動画）も扱いたい（5.8）。Kura は作画を支援するアプリで、アイデアボードと類似画像検索は画像でしか使えない。カテゴリは実際のフォルダに対応する（[ADR-0006](0006-no-relative-path-in-db.md)）。

## Intent (What)

- 1つのライブラリには、1つの種類の資料だけを入れる
- 利用者はライブラリを作るときに種類を選ぶ（FR-803）。アプリは、種類に合う形式のファイルだけを取り込み、種類に合わせて画面と使える機能を切り替える
- フェーズ1〜4で作ったライブラリは、画像のライブラリとして扱う

## Alternatives Considered

- **1つのライブラリに種類を混ぜる**：次の理由で却下した
  - 画像だけを扱う処理のあちこちに、種類での絞り込みが要る
  - 1つのフォルダに画像と .clip が並ぶ。種類ごとの画面には、資料が0件のカテゴリが並ぶ

## Consequences

- 今のテーブル、カテゴリとフォルダの対応、差分検出（FR-104）、ファイル操作の共通処理をそのまま使える
- 利用者は、種類の違う複数のライブラリを行き来する。同時に開けるようにするかは未決（`docs/requirements.md` の10章）
