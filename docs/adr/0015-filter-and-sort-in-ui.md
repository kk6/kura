# ADR-0015: 一覧の並べ替えと絞り込みを画面側で行う

## Status

accepted

## Date

2026-11-05

## Context (Why)

タグやカテゴリでの絞り込みの結果は、0.5秒以内に出す必要がある（NFR-02）。並べ替え（FR-506）はフェーズ1のタスク6で、絞り込み（FR-504）はタスク14で作った。

## Intent (What)

- 一覧を開いたときと取り込みの後に、ゴミ箱以外の全画像を1回だけ読む。画像ごとのタグの id とメモも一緒に読む
- 並べ替えと絞り込みは、読んだ一覧を画面側で処理する
- 2万枚で、押してから一覧が描き直されるまでを NFR-02 の 0.5秒以内に収める

## Constraints

- NFR-02：絞り込みの結果を0.5秒以内に出す

## Alternatives Considered

- 比べた案の記録はない

## Consequences

- 2万枚で、押してから一覧が描き直されるまで 16〜51ms だった（タスク14。Playwright の WebKit とモックの開発サーバーで測った）
- 一覧の全画像の情報を画面のメモリに持つ
