# ADR-0022: 観点ごとの類似度を平均0・標準偏差1にそろえてから重みを掛ける

## Status

accepted

## Date

2026-11-15

## Context (Why)

類似画像検索は、ポーズ・構図・内容の観点ごとの類似度に、利用者が決めた重みを掛けて並べる（FR-602）。スパイク（`spikes/similarity/`）で、類似度の幅が観点ごとに違うと分かった（内容は 0.40〜0.75、構図のグレースケールは -0.43〜0.52）。そのまま重みを掛けると、同じ重みでもグレースケールが約3倍強く働く。人物のいない画像では、ポーズの類似度がない（FR-605）。

## Intent (What)

- 基準画像に対する全画像の類似度を、観点ごとに平均0・標準偏差1にそろえてから、重みを掛ける（2026-11-15、スパイクで4つの方法を見比べて利用者が決めた）
- そろえる計算は、絞り込む前の、特徴量のある全画像で行う。絞り込みで並びが変わらない
- 重みは観点ごとに 0〜100 のスライダーにし、初期値は全部50。全部を0にはできない
- スライダーには、何を比べるかが分かる名前と短い説明を出す。「写っているもの（人や物、場面）」「明暗と線の配置（明るい所と暗い所、線の向き）」「体の姿勢（手足や胴の向き）」（2026-11-16、タスク11で「内容」「構図」だけでは分かりにくいと分かり、利用者が決めた）
- ポーズがないときの扱い（2026-11-18、タスク12・14で利用者が決めた）
  - 基準画像にポーズがないときは、内容と構図だけで比べる。帯には「体の姿勢」のスライダーを出さず、名前と理由（人物がいない、手足が足りない、未計算、モデルがない）を出す
  - 比べる側の画像にポーズがないときは、その画像のポーズの類似度を平均（そろえた後の0）とみなす。ポーズの平均と標準偏差は、ポーズのある画像だけで計算する

## Alternatives Considered

- **そろえない**：同じ重みでも、幅の広い観点が強く働くので却下した
- **最小〜最大を 0〜1 にそろえる**：スパイクで並びを見比べて選ばなかった
- **順位に置き換える**：飛び抜けて似ている画像との差が消えるので次点にした
- **人物のいない画像を結果から消す、または末尾に固定する**：ポーズの重みを上げても、人物のいない画像は真ん中あたりに寄るだけにした
- **使えない「体の姿勢」のスライダーを残す、理由をツールチップだけに出す**：モックで見比べ、利用者がスライダーを出さずに理由を出す案を選んだ（2026-11-18、タスク14）

## Consequences

- 重みのスライダーを動かしている間も、画面側で並びが追従する
- 類似度の数値は画面に出さない
