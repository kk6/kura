# ADR-0024: アイデアボードの操作とウィンドウの決まり

## Status

accepted

## Date

2026-11-09

## Context (Why)

アイデアボードは、描画ソフトの横に小さく置いて最前面に表示する（FR-705）。ギャラリーとボードの2つのウィンドウが同時に開く。フェーズ2の実装の途中で、仕様に書いていなかった操作を決める必要が出た。

## Intent (What)

- 画像の追加のダイアログでは、最後に使ったボードが削除済みなら、最近更新したボードを選択済みにする（2026-11-09、タスク4の実装時に置き、利用者が認めた）
- ボード上の画像は、⌘＋クリックでも Shift＋クリックでも、選択に追加・解除する（2026-11-09、利用者と決めた）。ギャラリーの ⌘ と、描画ソフトで多い Shift のどちらの手でも使える
- ウィンドウの位置と大きさは、ボードを閉じたときと Kura を終了したときに保存する。保存できなくても、閉じる・終了は止めない。保存した枠が画面の外に出ていたら、次に開くときに画面の中へ寄せる（2026-11-11、タスク11の実装で置き、2026-11-12 に利用者が認めた）
- 状態の枠（ゴミ箱・見つからない・削除された画像）では、反転・回転・グレースケール・トリミングを使えなくする。結果を見て確かめられないため（2026-11-12、タスク12で置き、利用者が認めた）
- 「ギャラリーで表示」は1枚を選んだときだけ使える。ギャラリーでダイアログを開いている間は、ウィンドウを手前に出すだけで選択を変えない（2026-11-12、利用者が認めた）
- ギャラリーで設定や確認のダイアログを開いている間は、ボードの最前面の固定を一時的に外し、閉じたら戻す。設定の値は変えない（2026-11-13、タスク17の実装で置き、同日に利用者が認めた）

## Alternatives Considered

- **Shift＋クリックを範囲選択にする**：ボードには並び順がないので、範囲選択には使わない
- **ウィンドウを動かすたびに位置を保存する**：閉じたときと終了したときだけにした。保存できなくても、失うのは次に開く位置だけなので、閉じる・終了は止めない
- **ダイアログ中も最前面の固定を続ける**：固定したボードの後ろにダイアログが隠れ、押せなくなるので却下した
- **ダイアログ中も「ギャラリーで表示」で選択を変える**：確認ダイアログの対象が、開いた後に変わってしまうので却下した

## Consequences

- ボードの選択の操作は、ギャラリーの選択（Shift で範囲選択）と異なる
- ダイアログを開くたびに、ボードの最前面の固定が一時的に外れる
