# ADR-0014: 人に見られたくない画像の印は、タグで代用せずに画像ごとに持つ

## Status

accepted

## Date

2026-11-05

## Context (Why)

利用者は、カフェなど人目のある場所で作業することがある。人に見られたくない画像に印を付け、印の付いた画像を出さないモードに切り替えたい（FR-513）。細部は 2026-11-05 に決め、作る時期は 2026-11-08 にフェーズ4と決めた。

## Intent (What)

- 印はタグとは別に、画像ごとに持つ
- 隠すモードでは、サイドバーの件数と「出ている枚数 / 全体の枚数」に、隠した画像を含めない。何枚を隠しているかは別に出す
- 隠すモードのオン・オフは、アプリを閉じても覚えておく。アプリ全体の設定に置き、ライブラリをまたいで効かせる

## Non-goals

- フェーズ2のボードに隠すモードを設けること。開いているボードとプレビューへの適用方法は、作るときに決める（`docs/requirements.md` の10章）

## Alternatives Considered

- **印をタグで代用する**：タグの名前の変更・統合・削除（FR-408）で印が外れ、画像が見えてしまうおそれがあるので却下した

## Consequences

- 印を付け外しする操作を、タグとは別に作る必要がある
