# ADR-0030: キーボードショートカットとメニューの決まり

## Status

accepted

## Date

2026-11-05

## Context (Why)

主な操作にはキーボードショートカットを用意する（NFR-12）。フェーズ1のショートカットは、タスク19で利用者と決めた（2026-11-05）。フェーズ2でボードの操作を足すときに、メニューとショートカットを決めた（2026-11-08）。

## Intent (What)

- ショートカットは、Finder やプレビューなど、macOS の既存のアプリと同じキーにそろえる（Space で拡大表示、⌘Delete でゴミ箱へ移す、⌘0 で原寸など）
- 入力欄の中では、文字の入力を優先してショートカットを効かせない。例外は ⌘F と ⌘, にする
- ダイアログを開いている間は、どのショートカットも効かせない
- フェーズ2では、既存のメニュー構成を保ち、ボードに必要な項目だけを足す。全体の構成の見直しはフェーズ4へ回す（2026-11-08 に決めた）
- メニューの「編集」の「取り消す」「やり直す」「すべてを選択」は、メニューから選んでもキーを押したときと同じ操作にする（2026-11-13、タスク17の実装で置き、利用者が認めた）

## Alternatives Considered

- **⌘A と ⌘Delete を入れない**：NFR-12 の「主な操作」には入らないが、Finder と同じ操作なので足した
- **「編集」のメニューに macOS の標準の項目を使う**：標準の項目は、ウェブの画面の配置や一覧に届かないので却下した

## Consequences

- キーの一覧は `docs/requirements.md` の6章にある
- メニュー全体の見直しはフェーズ4に残る
