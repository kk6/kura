# Kura の実装で学ぶ Rust・Tauri・React

この文書は、新しいチャットで1章ずつ学ぶための目次です。Rust と Tauri は基礎から読み直し、React は未経験から学べる順序にします。JavaScript・TypeScript も、読解に必要な構文を基礎編で確認します。プログラミング自体が初めての場合は、基礎編Aを複数回に分けて進めてください。目標は、エージェントが書いた Kura のコードを自分で追い、変更の意味や失敗時の動きを判断できることです。

実装の照合日：2026-11-13。基準コミット：`2f2bfcc658b78f319aad31fc2f36e36eee92be6b`。この照合ではアプリ実装の未コミット変更はありません。

## ガイドを作成・更新する

リポジトリの変更後は、次のように依頼してください。

```text
$update-learning-guide を使って、docs/learning-guide.md を現在の実装に合わせて更新してください。
React 未経験者向けの基礎編を維持し、読み先と前提知識、章プロンプトも確認してください。
```

スキルの正本は [update-learning-guide](../.claude/skills/update-learning-guide/SKILL.md) です。ガイドがない場合の新規作成にも使えます。自動で常時更新されるものではなく、機能追加や構成変更の後に呼び出して使います。

## 使い方

Kura を開いた新しいチャットで、下の「共通プロンプト」と対象章の「章プロンプト」を一緒に貼ってください。2回目以降は、前回の学習メモも添えると説明の重複を減らせます。

1章の目安は45〜60分です。難しい章は複数回に分けて構いません。演習の答えを先に読まず、自分の言葉で処理を説明してから答え合わせをします。

本文のパスはリポジトリルートからの相対パスです。学習開始時に実装を読み直す前提なので、行番号は固定しません。名前が変わった場合は、同じ役割の実装を探してもらってください。

## 目次と学習順序

React 未経験者は、基礎編A→B→C→第1章から順に進めます。基礎編は、Tauri や Rust を追わず画面側の短い部分を読む構成です。JavaScript・TypeScript に慣れている人は基礎編Aの理解確認から始め、React 経験者はB・Cも確認できた部分を短縮できます。

Rust を優先する場合も、第6章までに基礎編B・Cを済ませてください。第9章は React の基礎をつなぎ直し、経験者は過去の知識との差も確認する章です。既存の学習メモで参照できるよう、第1〜14章の番号は維持しています。

| 章    | テーマ                          | 到達目標                                   |
| ----- | ------------------------------- | ------------------------------------------ |

| 基礎C | state・イベント・再レンダー     | 操作で画面が変わる流れを説明する           |

## 基礎編A：JavaScript・TypeScript の読み方

Rust や React を学ぶ前に、画面側のコードで使う構文を確認します。変数、関数、オブジェクト、配列、分割代入、スプレッド、モジュール、型注釈、ユニオン型を扱います。Promise と async/await は後半で導入します。

読む場所：`src/galleryTypes.ts` の `Image` と `Category`、`src/filter.ts` の `Filter` と `NO_FILTER`、`src/App.tsx` の `saveSettings`。React の呼び出しはここでは役割だけ示します。

到達の目安：値と型注釈を区別し、オブジェクトの更新と Promise の成功・失敗の経路を説明できる。

```text
基礎編A「JavaScript・TypeScript の読み方」を教えてください。
まず変数、関数、配列、オブジェクトの理解を確認し、必要なところから始めてください。
Image と Filter を短く読み、分割代入、スプレッド、import と export を説明してください。
その後 saveSettings の try/catch と await を読みたいです。
React と Rust の知識を前提にせず、使い捨ての小さな例で不足する構文を補ってください。
演習は、値と型の区別、更新後のオブジェクト、非同期処理の順序の予想にしてください。
```

## 基礎編C：state・イベント・再レンダー

クリックや入力が state の更新につながり、React が画面を更新するまでを読みます。イベントハンドラを渡すことと呼び出すこと、props と state、制御された入力、データを親へ伝えるコールバックを学びます。

到達の目安：入力から次の描画までを追い、state を直接書き換える場合との違いを説明できる。

```text
props を受け取る向きと、コールバックで変更を伝える向きを区別してください。
イベントハンドラの登録と実行、state のスナップショット、不変な更新も扱ってください。
演習は、setState 直後に読む値と、続けて更新した場合の表示の予想にしてください。
```
