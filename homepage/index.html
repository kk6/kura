Kura蔵

イラスト制作用の参考画像を、パソコンの中だけで取り込み、整理し、探すための macOS アプリです。外部のサービスを使わないので、サービスの規約や判断で資料を失うことがありません。

ダウンロード GitHub 無料・オープンソース（MIT）／ macOS（Apple シリコン）

できること

  • 普通のフォルダに置く

    画像は普通のファイルとして置きます。Kura がなくても Finder で開けます。

  • フォルダごと取り込む

    フォルダの構成はカテゴリとして再現します。中身が同じ画像は重複として取り込みません。

  • カテゴリとタグで分ける

    複数の画像にまとめてタグを付けられます。タグは AND と OR で絞り込めます。

  • 縦横比を保って並べる

    並べ替え、サムネイルの大きさの変更、拡大表示ができます。

  • ファイル名やメモで探す

    メモと星5段階の評価を付けて、検索に使えます。

  • 消しても戻せる

    削除した画像はアプリ内のゴミ箱に入ります。空にするまで元に戻せます。

  • Finder での変更に追従する

    Finder で画像を足したり動かしたりしても、検出して反映します。

  • 外へ送らない

    画像も管理情報もパソコンの中だけに置きます。

インストール

  1. Releases から Kura-<版>-arm64.zip をダウンロードする
  2. zip を展開し、Kura.app を「アプリケーション」フォルダに移す
  3. Kura.app を開く

Kura は Apple の開発者の署名と公証を受けていません。初めて開くときは macOS に止められるので、次のどちらかの方法で開きます。一度開けば、次からは普通に開けます。

  • Finder で Kura.app を右クリックし、「開く」を選ぶ（macOS 14 まで）
  • 一度開こうとして止められたあと、システム設定の「プライバシーとセキュリティ」で「このまま開く」を押す（macOS 15 以降）

動く環境は Apple シリコンの Mac です。ライブラリは内蔵ディスクか外付けドライブ（APFS、HFS+、exFAT）に置きます。
